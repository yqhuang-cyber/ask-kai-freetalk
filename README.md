# Ask Kai 自由对话

从 Ask Kai 提交 `0da0bcd` 复制出的自由对话切片。这个目录只有一个学生入口：自由聊天。主题管理和 Mission 后对话不在这里启动，也不出现在页面上。

## 这条链路

1. 打开学习页，选择一位本地 mock 学习者。
2. 准备对话时只读取个人画像、学习画像和近期学习记录。初始没有教学目标，不读取课程或主题包。
3. 规划模型可用时提出计划；超时、格式不合格或服务不可用时，改用规则计划，并在页面上标明。初始化总时限 15 秒，逐轮最多 2 秒。
4. 学生明确要求持续练习时，才从通用技能目录选择一项。普通交流可以没有任何知识点。
5. 开始对话后使用豆包实时全双工。当前是后续建议，不能证明这一轮语音先经过规划再生成。
6. 结束时给出有来源的小结。只有学生勾选保存，才会写入本地 mock 内存；重启后消失。不保存原始音频或逐字稿，也不把尝试升级成掌握。

还要完善的事项见 [自由对话链路审查](docs/free-conversation-engineering-review.md)。

## 启动

需要 Node ≥ 22.18。

```bash
npm ci --ignore-scripts
npm run poc
```

学习页是 http://127.0.0.1:4310 。真实语音仍使用本机 `.env` 里的豆包配置；没有密钥时可以查看入口和偏好，不能开始真实对话。

工程检查：

```bash
npm run verify
npm run replay
```
