# Long-session regression v2

2026-10-15。保留 v1 原文件，v2 沿用相同三个会话、44 轮输入，仅修正 free 的产品契约断言：

- free 不再读取运动课程；通用技能均为 unassessed，因此全程没有可保存的 attempted。
- 通用时间表达没有“先独立表达喜好”的先修；学生明确选择后可以 active，普通交流继续保留，明确结束时暂停。
- 主题和 Mission 的断言不变；拒绝、局部求助、来源版本和 shadow 候选不能写成学习事实的约束继续检查。

修改依据是入口与证据边界，不是模型输出；所有期望都只进入评测，不进入 Planner。v1 仍可用于历史比较，其中 free 的旧课程契约与当前实现不兼容。`npm run eval:agent:long` 默认运行 v2。真实模型、语音内容及设备体验仍分别验收。
