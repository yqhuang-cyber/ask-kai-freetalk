## 本轮完善

1. 244 轮新增独立语言预期，按声明画像、明确已知自述和当前请求标注。原代码预览降为诊断信息，不再定义正确答案。主集画像缺失仍保持 unknown，补充对照覆盖 beginner、comfortable、auto、zh、zh_en 与临时求助/恢复。案例 037 的茶仅从第 11 轮算明确已知自述，允许短复习提示省英文，不推成新学或能力下降。
2. 244 轮新增必须满足检查点、关联十维、0/1/2 分锚点和明确关键失败条件；33 个关键回合另给具体的满分、部分满足和失败判定。原十维、权重、评分与 critical_failure/blocked 门槛不变。自然聊天、暂停、结束可以得到合格的 progress；不强制每轮教学。
3. 244 轮均新增符合当前策略的简短示例，原参考独立保留。除 007 第 3 轮明确精确输出外，允许自然等义替代。模拟价格不要求十元，问价或点水不要求唯一句式。没有明确拼音请求时，不把口头拼音重复设成硬要求。
4. 40 个案例分别补总结主题、可纳入表达、来源轮次及必须保留的事实范围。内容只在实际呈现或尝试后纳入；候选清单不要求全出现。Miso睡沙发、森林未改海、钢琴/吉他人物分工、角色身份、早餐茶范围等分别检查。没有现有卡片支持时允许交流/空态，不要求添加任意新词卡。
5. 补前文依赖与偏离处理。回放只用学生输入和实际此前Kai回复。若固定脚本依赖的语义没有实际出现，先记录最早偏离，对依赖检查标 context_mismatch，继续独立安全/指令检查；不借参考回复补造前文，也不把重复连锁偏离计作多个独立缺陷。

## 使用

Excel 中先看“案例”，再按编号筛选“规范逐轮”和“评分锚点”；“语言对照”是补充条件，不改变原始案例。黄底复核字段可填写人工意见。“原始逐轮”完整保留输入与原参考。

JSON 的 version=2，状态 prepared_not_executed。expected.language_ground_truth、criteria、dimension_anchors、reference_candidate 和 summary_contract 是评审数据；给待测模型的内容只有必要初始条件、学生输入及实际此前Kai回复。完整 JSON 不能直接当作生产模型提示词或现有 eval:content 的实际输出。

仓库离线校验入口：npm run eval:dataset:check -- /absolute/path/ask-kai-freechat-eval-v3.json。它检查结构、来源、泄漏、计数和规则版本，不调用模型、不对语义评分。后续真实回放与原十维评分应分别保存实际回复、版本、context_mismatch 和覆盖状态。

本次没有调用豆包或 Judge，没有模型得分。语速、插话、渐进字幕、实际听辨/发音和另外两个入口仍属于单独的真实验收。

Excel 中文单元格内容已逐格核验。当前预览环境缺中文字体，无法完成中文排版的完整视觉核验；导出内容保留完整，未用预览截图代替数据。
