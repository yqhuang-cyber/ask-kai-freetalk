# Ask Kai Agent 独立评测计划

2026-10-15 · 规划，尚未执行新评测。对应 [模块任务清单](agent-completion-tasking.md)，评测运行器是验证支撑，不是生产 Agent。

## 1. 评测目标与现有证据

最终评价三个入口对不同学习者的实际整场对话，而非仅判断 Planner 输出合法。分别检查：计划是否合理、执行是否真实、反馈与证据是否可靠、对话是否有用、实时音频是否可用。

现有测试／replay、规划 fixture、20 个反馈案例、三会话／44 轮长会话是工程保护；真实 M3 结果有较多规则降级。最新旧 Harness 真实内容记录为 24/26 案完整、145/149 轮评分，103 通过／29 待复核／13 失败，主要是 free 与语言对照，不能外推为三入口适配验收。原始报告及冻结分数保留。28 项初始化设计案例尚未进入运行评测；模型／Judge 调用为 0。见 [历史正式结果](eval-results/2026-10-13-harness-formal-comparison.md)、[四项工程结果](eval-results/2026-10-14-agent-four-tasks.md)与 [初始化案例说明](eval-datasets/initial-planner-adaptation-v1/README.md)。

## 2. 独立任务与顺序

| ID | 任务／产物 | 依赖与完成条件 |
| --- | --- | --- |
| AE-01 | 冻结最终目标、候选基线、评测协议与校准样本；登记既有 Web 验收的实际覆盖 | 保留旧 rubric／分数；新增适配／证据要求单独版本；调模型前冻结 holdout；未校准不出质量通过结论 |
| AE-02 | 建立覆盖矩阵与新三入口 harness；复用生产准备、授权、会话及实际输出链路 | 原 recorded adapter 绑定 free，不能直接把 entry 改名；新增版本化入口／资源／四背景适配和最小学习记录审计；输入／oracle 隔离 |
| AE-03 | 初始化与逐轮规划：28 项设计案例物化、成对关系、真实候选模型及 holdout | IP 契约和资源实施后接入；原 12 案／18 轮、20 案反馈保留保护；结构、语义、降级与延迟分别报告 |
| AE-04 | 正式执行因果与遵循评测 | 先 M5 独立能力核验，再 M2 正式链路；检查 plan→宿主生成请求→response，首轮／advisory／controlled 分组，不从 ACK／延迟播放证明门控 |
| AE-05 | 语义观察、提示来源、反馈、总结与写回证据 | shadow 候选先独立校准；支持范围、误报／漏报、unknown、取消与更正分别检查；播放回执不能认证听到／理解 |
| AE-06 | 三入口整场内容、能力适配、长会话及版本对比 | AE-02 完成后分批采集；实际 Kai 前文，盲审十维＋逐项要求；残留语言／澄清／结束／支架失败按类回归 |
| AE-07 | 真实语音、浏览器设备体验与恢复 | 先 synthetic 浏览器保护，再真实 provider 作者音频，再耳机／扬声器真机；判停、插话、AEC、字幕、首响、重连与关麦分别验收 |
| AE-08 | 权限、安全、隐私及 mock 跨会话闭环 | 三入口测跨学生、注入、撤权、风险、留存／删除；mock 人工接手不可计成功，真实生产接手不属本次 POC |
| AE-09 | 最终候选重跑、分层报告与完成裁决 | 同版本证据齐全；报告全部分母、失败／复核／缺口、退化、成本和限制；必要项未通过时保持未完成 |

AE-01／02 先行；AE-03 与供应商能力实验可分别准备。AE-04／05 随模块落地；AE-06～08 验整场；AE-09 最后。评测缺陷归评测任务，Agent 缺陷回写 AC／DP／IP／TT 的原任务，不能修改 oracle 让候选通过。

与最新 [TP tasking](topic-planner-tasking.md)对齐：AE-02／03 复用 TP-04，不重复实现。单独评测生成器、准入／发布／回滚／撤销、重启后读取、cache miss 零生成；Planner 个性化比较固定同一已发布 pack hash，避免生成随机性混入。运动、第二主题及未调 prompt 的主题 holdout 分组。新逐轮总预算最多 2 秒，包含排队／修复／校验／提交；生成管理端预算与学习者初始化等待分开。预算代码当前正在改动，冻结候选时以实际源码 digest 为准，不提前宣称真实时延通过。

## 3. 三入口 × 四背景覆盖

以下为拟议最小新增核心集，非已存在或已采集结果。每个单元至少 3 个完整作者场景：自然交流、需要／支架变化、学生控制与收束。共 12 个单元、36 个场景；每场拟 6～10 个有效学习者话轮，实际轮数在 AE-02 冻结。另准备每单元一个独立 holdout，共 12 个场景；不把原案例改名当作泛化。

| 背景需要（不是固定目标答案） | Mission Call | 运动主题 | 自由聊天 |
| --- | --- | --- | --- |
| Alex-like：基础喜好／时间稳定，频率需局部支持 | 课程内容带到生活中的频率／安排 | 给符合近期需要的低负担机会，不重教喜好 | 跟随当前选题，按需给局部帮助 |
| Maya-like：基础顺序稳定，长经历的信息取舍需支持 | 仅在授权应用方向内组织经历 | 接住真实经历，帮助突出原因与关键事件 | 自然交流，求助不变整场考试 |
| Leo-like：理由／例证不足 | 有授权能力才引导具体例子，否则合理无目标 | 观点讨论，一次一个理由或例子 | 保持意思与立场，回应和相关追问 |
| Nina-like：观点过于绝对 | 授权范围允许时练适用范围／措辞 | 简短讨论与可选限定表达 | 不制造错误或强制反驳，允许零教学 |

这些需要对应最新 mock-learners-v2／TP 集成方向，AE-02 须冻结实际一致的资料与近期证据。原 28 项设计案例使用其原背景单独报告，不改历史输入或 oracle。高阶 Mission 不能仅因 learner 等级就越权选择资源；若无适合资源，“无目标交流”是有效边界样本，但还需另一份合法资源样本验证实际教学能力，不能用全部 null 逃避覆盖。

额外边界集至少覆盖：只改兴趣、只改需要、同等级不同需要、改姓名／UID／等级标签、反转资源／历史顺序、资料缺失／冲突／截断、资料注入、缺适合资源、拒绝／恢复、当前选题覆盖旧兴趣、单次求助与持续练习、语言偏好作用范围、正确句／歧义对照、停止／打断／迟到／重复、更正、写回失败。复用现有不变量负例，新契约受影响项重新运行。

长会话另设三个入口各一整场，覆盖暖场、内容推进、支持变化、目标暂停／改选、局部帮助失效与收束；每场拟 20～30 个有效话轮或进入实际上下文裁剪边界。遵守当前会话时长和预算；不能用 synthetic 快速 44 轮证明真实 10 分钟体验。故障集与安全集独立列，规模与样本在 AE-02 冻结。

## 4. 评分对象与方法

| 层 | 评价对象 | 检查与不能推断的内容 |
| --- | --- | --- |
| 工程 | 授权、版本、归属、时效、幂等、取消、错误 | 必须确定性通过；不证明自然对话质量 |
| 规划 | 目的、需要、目标／null、支持、一个行动与合理理由 | 多解允许；合法 refs 不证明适合；同目标不自动失败，目标名称不同不自动成功 |
| 执行 | 实际上下文、生成请求、response、文本、音频、回执 | 分 planned／generated／forwarded／client-reported playback；供应商内部起点未知则保留未知 |
| 观察与反馈 | 实际学习者表达、KP 关系、支持来源、取消／更正、总结／写回 | 引语／自述／教师输出不是学习者表现；未校准技能不可登记正式成绩 |
| 整场效果 | 意图、难度、追问、纠错、语言帮助、控制权、连贯与收束 | 评价实际回复与学生表达机会；free 不强制教学；作者输入不能证明真实学习进步 |
| 音频体验 | 完整表达到可听首响、抢话、停播、恢复、字幕、回声 | 真机统一测量基准；供应商首包、浏览器调度与可听首响分开 |

沿用十维与原权重：意图15、正确性15、指令10、难度12、表达8、连贯8、目标推进10、个性化5、人格5、安全12。评分 0／1／2，逐项要求与关键失败单独保留。新增规划、执行、观察及整场适配评分独立输出，不反向改写旧十维结果。

盲审只见当前实际前文、当前回复、获准资料／资源和评审要求；运行 Agent 不见 oracle、参考回复、未来话轮或评分标准。规划审阅使用接受前原始快照，不从修订后状态重建。当前 M3 自审仅为辅助模型审阅；语义质量验收需教研／人工校准，独立 Judge 配置后仍须校准，不把另一次模型调用当成天然真值。

观察校准须区分表达语义、角色归属、提示程度、情境与独立性。先验“表达候选”正确性，再验提示／时间关联；缺后者不能输出独立／迁移。未校准的高阶技能可以产生适合的实践方向，但总结继续 unassessed。POC 不把自然对话表现宣称为永久掌握或官方等级能力。

## 5. 放行门槛

最终采用严格的案例／逐项要求验收，不能以均分较高代替：

1. **覆盖完整**：12 个单元核心集及 holdout、长会话、关键边界／故障／安全集全部执行；必要话轮与要求有证据，缺失为 missing，非通过。技术失败作为独立失败保留，重跑不覆盖原记录。
2. **硬门槛全通过**：权限、跨人、控制权、来源真实性、重复写入、安全与凭证边界零关键失败；取消／迟到不能污染新回复。真实人工接手不在 mock POC 的通过分母中。
3. **语义无悬空**：最终预注册必要案例与要求通过校准后的判定；failed／review／unassessable 必须修复或补证，必要项有缺口则不放行。沿用现有逐轮 passed／review／failed 口径；不在看到结果后调门槛。
4. **分层合格**：按入口、需要背景、首轮／后续、LLM／rule、执行路径分别看结果。每个单元都合格，不用 free 的大样本平均掩盖 Mission／主题缺陷。规则降级可通过合规性，不能计为 LLM 规划成功。
5. **执行能力可信**：受控路径须通过正式因果与故障样本；若仍为 advisory，明确报告后续建议遵循，保持完整受控闭环未完成。
6. **体验先定后测**：首响、抢话、打断停播、恢复与字幕容忍值在 AE-07 基线／人工校准后、候选对照前预注册；初始化 10 秒和新逐轮最多 2 秒是规划预算，不是体验 SLO，须另测真实完成率、语义质量及 overrun。目标尚未冻结则不能宣布设备合格。
7. **回归可解释**：受影响原关键集重跑，无新增关键失败；所有退化复核。修复失败类用新独立会话复验，并保留至少两次结果防止单次偶然通过；重复次数不代表统计显著。

每轮报告关键失败数、通过／失败／复核／不可评、可比较范围与全分母。可报告均分和通过率，但它们不单独决定最终完成。

## 6. 三类验证严格分开

| 验证类别 | 执行方式 | 结论边界 |
| --- | --- | --- |
| Synthetic | `npm run verify`、`npm run replay`、离线 planning／goals／agent／long、合成设备 browser | 工程和契约；不代表真实 LLM、豆包或听感 |
| Real provider | 显式 live Planner；固定作者合成音频经真实豆包生产路径；协议／门控独立 probe | 区分真实规划模型与真实语音连接；真实供应商＋作者音频不等于真人设备或真实学习效果 |
| Browser audio／设备 | 耳机与扬声器；实际采音播放、弱声／噪声／口音、思考停顿、插话、页面退出 | 可听时序与 AEC；普通 Web 已确认部分保留，新路径及改造受影响项另验 |

现有可复用命令：`eval:planning`、`eval:goals`、`eval:agent`、`eval:agent:long`、`review:planning -- --preflight`、`eval:candidate`、`eval:recorded`、`eval:report`、`test:browser`。28 项 IP 案例与三入口全量集尚无兼容命令，属于 AE-02／03 的工程交付，不能直接拿现有 free adapter 运行。真实调用仅在显式评测批次使用所需配置；本次规划没有启动。

## 7. 结果产物与收尾

每批产出 candidate manifest、coverage、planning、execution、observation、content、audio、safety/privacy、comparison 和最终 acceptance。至少绑定代码提交及工作区源码 digest、资源／画像 revision、模型／profile、prompt／policy、数据集／oracle／rubric hash、Judge／人工校准版本、路径、实际调用数、成本及 unknown。工作区有未提交变化时不能只绑定 HEAD。

记录 planned／attempted／completed／scored 全分母，以及 LLM accepted／rejected／timeout／rule fallback、真实 provider ready／回复完整／取消／恢复、browser synthetic／设备实测范围。预期来源、实际输入、ASR 偏离、原始事件归属与评审结论分开。

评测正文仅使用作者合成材料或明确授权材料；真实逐字稿／音频与 provider trace 不入 Git，私有产物仍按用途／留存管理。默认 Web 不新增完整录音或逐字稿保存。可选 Langfuse／Judge 不是完成 POC 的强制基础设施。

AE-09 仅在必要门槛全通过时宣布“本地 Mock 业务下，三个入口对已测背景的自适应对话 POC 完成”。未满足时报告具体未完成任务；不因文档、测试数量或一次演示就将正式服务、儿童保护或长期学习效果列为通过。
