# 规划器更新：按学习者调整 Kai 的交流与中文难度

日期：2026-10-18（Asia/Shanghai）。修订版需求；尚未实现。技术方案见[详细设计](planner-speaking-difficulty-design.md)，验收输入与判定见[验收案例](planner-speaking-difficulty-cases.md)。[原始草案](planner-speaking-difficulty.md)保留供对照。现有行为仍以[自由对话 Planner](free-conversation-planner-summary.md)、README 和 implementation-plan 为准。

## 1. 产品目的

不同学习者进入自由对话后，Kai 应根据已授权画像、近期学习实例和实际交流，决定：聊什么、如何接话、何时提供多少帮助，以及自己使用多难的中文。学生感受到的差异必须出现在实际回复中，不能只在后台换一个 HSK 标签。

本次重点补上最后一项。**帮助学生表达的程度，与 Kai 自己说话的难度分别决定。**学生暂时说不出一句话，不代表听不懂相同难度的中文；学生能讨论抽象问题，也不代表认识所有高级词。

沿用现有计划的内容与支持字段，新增明确的说话难度，不新增必做教学任务。自由聊天开场的 `primary_goal_id:null`、`candidate_goal_ids:[]`、`key_points:[]` 保持成立。

## 2. 哪些计划字段因人而异

| 学生体验 | 初始计划字段 | 逐轮计划字段 | 判断依据 |
| --- | --- | --- | --- |
| 交流目的与方式 | `conversation_purpose` | `interpretation.intent`、`reply_directive.task` | 当前需要、交流偏好、实际意图 |
| 内容切入 | `content_focus` | `reply_directive.task` | 兴趣和近期实例；学生当前话题优先 |
| 如何开场或接话 | `opening_options`，最多两项候选，实际只选一项 | `action`、`reply_directive.task` | 实际上下文，不机械重复或每轮提问 |
| 帮忙程度 | `strategy.support_level` | `reply_directive.support_level` | 表达困难、帮助请求；支持级别不是要求每次示范 |
| Kai 的中文难度 | **`strategy.speaking_difficulty`** | **`reply_directive.speaking_difficulty`** | 听力与理解反馈优先，HSK 限制词汇范围 |
| 为什么这样选 | `selection_basis` 与难度中的 `reason/refs` | `evidence_refs`、难度中的 `reason/refs` | 有来源的资料与当前输入；不能虚构能力缺口 |

语言支架、纠错、语速仍走原来的字段和作用范围。初始值来自授权资料，页面显式选择的语速覆盖画像语速；会中直接语言请求继续按现有语言策略处理，不被旧画像盖回去。较少英文不意味着应该使用更难的中文，慢速也不意味着中文词汇等级更低。

## 3. 模型和程序各负责什么

开场连接前调用规划模型；每个被接受的有效学生回合，除结束等既有控制路径外，再调用同一个逐轮规划模型。难度随原计划一次生成，不另加一次模型请求，不增加现有逐轮 2 秒总预算。

模型结合以下资料作出选择，而非按姓名填写四套固定配置：当前学生的明确需要及实际前文；学习画像中的听力描述、近期理解修复和表达实例；当前 HSK、学习阶段、交流偏好与资料覆盖情况。

程序绑定可信 HSK 范围、检查枚举和引用、处理明确请求的作用范围、隔离迟到计划。模型没有配置、超时或提案无效时，才用有标记的规则兜底。模型生成失败必须可见，不能把固定规则输出算作模型个性化通过。

## 4. 说话难度的三个选择

初始和逐轮使用同一对象，字段定义见详细设计。

| 维度 | 可选值 | 含义 |
| --- | --- | --- |
| 用词方式 `lexical_style` | `everyday` / `precise` | 优先常见直接说法 / 允许范围内更精确的措辞；都不能抬高词汇上限 |
| 句子组织 `sentence_structure` | `simple` / `linked` / `flexible` | 简单结构、每句一个重心 / 按时间或因果分步连接 / 按需要组织比较、条件与限定；不是固定句数或回复长度 |
| 新词策略 `new_word_policy` | `avoid` / `one_explained` / `requested_only` | 不主动安排新词教学 / 最多主动解释一个范围内的词 / 只处理学生正在问的词 |

另有 `focus_term`（无明确词时为 null）和简短 `reason/refs`。抽象观点属于交流内容，不能拿它代替句子组织选项。简单句也能讨论有深度的问题；高等级也可以选简单句。

`avoid` 不声称程序知道学生认识每个词，只表示优先有依据的熟悉表达、不主动安排新词教学。学生明确没听懂时，进一步用短句重述同一意思，不再引入新概念。语法负担和信息组织仍由模型判断与内容评测确认，不能仅靠词汇上限证明可理解。

## 5. HSK 词汇范围

本版沿用原需求的严格默认：普通主动用词以画像 `course_level` 所表示的当前已达等级为上限，不用下一阶段 `current_study_scope` 作为上限。完成该级别不等于认识该级别所有词。四位学习者是已模拟完成 HSK1、3、5、7；不是正在初学这些等级。

- 本仓库采用 `hsk-2025-syllabus-v1` 目录，不混用其他版本的同名等级。
- Alex 的普通主动用词限制在一级；Maya 在一至三级；Leo 在一至五级。
- 学生明确问某个超纲词时，可以说出该词并用范围内的话解释；例外只用于当前所问词，不扩成整轮提高等级，不登记为已掌握。
- 兴趣、历史里出现过的超纲词不会自动成为例外。若以后允许“已知超纲词”，另加有来源的规则；本版不隐式放宽。
- 专名、数字、组合词和义项不能靠简单字符串匹配判定等级；无法确定的内容标为待复核，不能自动判通过。

七至九级在本仓库是共同目录，无法精确拆出七级全部词。Nina 的目标等级仍记录为七级，但普通主动选词先使用可核对的一至六级范围；共同目录中尚无独立七级依据的词不主动引入，当前问词例外仍适用。她的观点深度与句子组织不因此降为初级。将来补齐有来源的七级划分后再扩展可核对范围，不用整个高级目录替代七级上限。

仓库已有[完整 11,000 条词汇目录](../apps/hskai-mock/data/hsk-2025-vocabulary.json)。本次不做在线播放前逐词拦截；离线验收可以用该目录辅助复核。字段合规、上下文已下发、实际用词合规，是三个不同结论。

## 6. 当前请求与生效范围

| 学生表达 | 本次处理 | 持续时间 |
| --- | --- | --- |
| “刚才那句没听懂”“这句说简单点” | 常见词、简单结构，解释同一意思，不加新概念 | 归属到当前修复回复；完成或新输入后不作为硬设置自动延续，但后续模型仍能看到这次反馈 |
| “以后都说简单一点” | 建立会话内简化约束；模型只能在其中选择 | 当前会话直到明确撤销；不写回长期画像 |
| “声音没听清，再说一遍” | 优先重复或澄清同一内容，不自动推断词太难或能力下降 | 当前回复；不自动改语速 |
| “swimming 中文怎么说” | `requested_only`；明确当前词，必要时解释，不追加别的新词或练习 | 当前词义／翻译帮助；歧义时先澄清 |
| “先别结束，我还想聊”／明确告别 | 沿用既有继续／收束控制；仍使用合适的中文 | 不因新增难度字段改变结束判定和关闭流程 |

引语、否定、转述不能当成学生本人的新设置。程序先在本地形成与当前输入绑定的约束，模型不能放宽它；它何时影响语音取决于实际上下文应用边界。

开场难度写入初始语音指令，作为会话基础。逐轮难度为有归属的后续建议：旧回合的临时问词或简化要求不能覆盖新输入。当前全双工会先自动生成回复，因此本版不承诺“每句都等 Planner 再生成”。学生当前请求同时受初始全局指令约束；若实际语音未遵守，应报告内容失败或应用时机缺口，不能凭计划正确宣称已生效。细节见详细设计第 6 节。

## 7. 四人的开场对照

以下均为作者设计的预期方向，**不是模型实测、固定模板或送入 Planner 的参考答案**。允许同等合适的其他内容与说法，不能按逐字一致验收。四人都没有正式目标，语言支架按需、纠错温和；Alex/Maya 慢速，Leo/Nina 正常。

### Alex：已完成一级，进入二级

- 交流目的：聊一件具体生活小事，让他能用已会的短句接上。
- 内容切入：和朋友的日常活动，保留他的运动兴趣作为背景，不要求 Kai 在开场主动使用超纲运动词。
- 可选开场：“你今天想做什么？”或“你今天和朋友做什么？”；实际只问一个。
- 帮忙程度：`model`，表示卡住时允许一句短示范，不是开口先教“我喜欢”。
- 说话难度：`everyday / simple / avoid`；普通主动用词到一级。
- 理由：熟悉生活场景的喜好、时间和地点表达已有合成证据，频率与经历需要局部帮助。不能从进入二级推断所有二级词已知。

原稿的“周末／踢球／篮球”不作为一级严格封顶的合格开场示例；词表分别包含三级“周末”和二级“踢、球、篮球”。若学生主动问这些词，走当前问词帮助。

### Maya：已完成三级，进入四级

- 交流目的：让她先叙述自己的活动，有需要再帮她组织先后顺序。
- 内容切入：一次跑步经历，而不是重教基础喜好句。
- 可选开场：“你跑步的时候，发生了什么？”或“你这个星期跑步几次？”；实际只选一个。
- 帮忙程度：`partial`，她先说，卡住再给一点提示。
- 说话难度：`everyday / linked / avoid`；用词到三级，允许按顺序展开。
- 理由：熟悉经历和简单原因能独立表达，长叙述的信息组织仍可需要帮助；不能因一次卡住将基础知识改为未学。

### Leo：已完成五级，进入六级

- 交流目的：讨论一个选择，帮助他把理由说具体。
- 内容切入：个人技术和团队配合，不强制完成某个句型任务。
- 可选开场：“你觉得个人技术和团队配合，哪个更重要？”或“你最近看的比赛里，哪个配合让你觉得有用？”
- 帮忙程度：`partial`，先聊内容，理由过空且影响意思时再点一下，不默认纠错。
- 说话难度：`precise / linked / avoid`；用词到五级，可以更准确，不主动加六级词。
- 理由：比较和说明原因已有背景证据，近期需要是具体例子，而不是给整段一级示范。

### Nina：达到七级交流水平，继续深化高级表达

- 交流目的：平等讨论观点，在需要时帮助限定判断的适用范围。
- 内容切入：比赛结果、规则和公平，不以高级词数量证明对话有深度。
- 可选开场：“如果只看比赛结果，你觉得这样公平吗？”或“你觉得同样的规则对所有人都公平吗？”
- 帮忙程度：`partial`，先接住立场；实际语气或范围影响意思时再轻提示。
- 说话难度：`precise / flexible / avoid`；目标等级七，普通主动选词使用当前可核对的一至六级范围，高级共同目录保留未精确分级状态。
- 理由：能讨论抽象问题，但判断范围与语气还需情境化打磨；不能把七至九级共同词汇视作全部已掌握。

示例是自然表达候选，除明确核对的词条外，不冒充整句词义、分词与理解难度的自动审定。验收仍要检查实际输出。

## 8. 验收与交付边界

本次设计要求后续实现分别交付：计划契约、初始与逐轮提示传递、请求作用范围、降级、诊断证据和独立案例。具体代码落点与实施顺序见[详细设计](planner-speaking-difficulty-design.md)，四人字段矩阵及同等级反例见[验收案例](planner-speaking-difficulty-cases.md)。

验收分开报告：合成契约检查、真实 Planner 选择、实际豆包回复、浏览器播放听感。四人开场检查是其中之一；还需同等级不同听力、同一人求助前后、兴趣变更、超纲问词、模型降级和迟到结果案例。计划合格不能代替语音内容合格，合成回放不能代替真实连通。

本轮交付只有需求修订、详细设计和验收规格；运行代码、供应商配置、已有冻结评测与得分均不改变。

| “帮多少”和“说多难”没有清晰字段分工 | 保留原有内容／支持字段，初始与逐轮各增加同形难度对象 |
| 选项重叠，抽象讨论混进句子难度 | 拆成用词方式、句子组织、新词策略；内容深度仍在交流任务中 |
