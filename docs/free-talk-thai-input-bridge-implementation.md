## 使用与配置

中泰页面新增“你现在说的语言”。选中文时，麦克风音频进入原生 S2S，不调用外置 ASR；选泰语时，音频只进入固定 `th-TH` 的独立 ASR，再由 M2 将最终转写交给 S2S。此选择控制输入语言，回复仍使用中泰规则。系统没有自动判断或自动切换语言。

已有 S2S 配置不变，新增 `DOUBAO_ASR_API_KEY`（专用 ASR Key）、可选 `DOUBAO_ASR_RESOURCE_ID`（默认 `volc.seedasr.sauc.duration`）。配置专用 ASR Key 后，中泰启动默认启用手动分支；也可显式设 `ASK_KAI_THAI_INPUT_MODE=manual`。回退旧链路设为 `native` 并重启中泰服务。无专用 ASR Key 且未显式开启时保持旧链路；显式开启但凭证无效会启动失败，不静默回退。

正常会话边界可切换输入语言。识别、回复或切换过程中先打断再切换；切换等待已有上下文或取消确认完成。泰语输入按约 700ms 静音分句，单段约 13 秒上限，超长提示缩短重说。这里的声学分句不是语言检测；噪声、远场、停顿和回声仍需真人设备验证。

## 泰语如何交给 S2S

当前 S2S 的原生文本问答没有在前期 Spike 得到可靠证明，因此采用已验证的历史加音频 workaround：ASR 收到最终文本后，将原文写入新供应商连接的初始历史，配一个明确的程序占位助手消息；等实际历史读回完全匹配，再发送固定音频“请回答。”。它只用于激活回答，不算学生输入，也不是通用唤醒词服务。

M2 保持同一业务会话，供应商连接可以按泰语回复重建。历史最多保留 6 组已转发问答并另设长度限制；这不是完整 Agent 上下文，取消的输出不进入历史。历史核验、程序触发识别或回复归属失败时拒绝继续，不用合成 ACK 冒充供应商确认。

触发音频是仓库自制的约 0.795 秒中文控制素材，manifest 校验文本、格式和摘要；不是学生录音或供应商音频。真实对照的 3 个问题中，短触发均回答正确；中位首次音频为 3.390 秒，长触发为 5.947 秒。样本量小，不能据此承诺生产延迟。

## M2 控制与隔离

泰语明确结束意图由 M2 进入收尾，提交固定中泰告别文本给供应商发声，并显示这段已提交文本。必须等匹配回复的实际浏览器播放完成回执后才结束业务会话。字幕是已提交的发声内容，不是独立验证的语音转写，也不证明学生已经听到。普通聊天中模型自行说出告别句，不会单独触发中泰分支挂断。

手动打断或新语音会取消待处理 ASR、停止旧输出并隔离迟到结果。泰语本地连接隔离明确标记为 M2 取消，不冒充供应商取消 ACK。继续聊可撤销收尾，旧播放回执不能关闭新回合。识别到单独的 Kai 呼叫时由 M2 回应；声学分句和简单文字意图规则不保证覆盖全部自然表达。
