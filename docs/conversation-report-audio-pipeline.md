# 作业报告音频评测链路

日期：2026-10-28（Asia/Shanghai）。分支：`codex/report-analysis`。用户没有现成测试录音，授权先补齐链路。本轮为**人工核对的 POC 工程路径**，不声明自动声源判断、实际发音准确性或整个报告 feature 已验收。

## 新会话流程

1. 当前处理用途说明升级为 `deep-report-notice-v5`。核对模式配置生效后，新会话默认保存文本和测试录音，不额外显示文本 / 音频勾选框；学生在开始前看到简短用途说明和可展开的留存 / 撤回说明。
2. 麦克风片段按已有候选分段和授权保存在 M4，封口清单绑定样本范围、字节 hash、元数据 hash 与提交。原始声源、噪声等仍诚实保持 unknown；能量检测不是可靠的说话人识别。
3. 提交后先运行后台文本与音频任务。没有核对过的音频不发给腾讯；学生看到“录音等待核对”，不先看到基础反馈或最终报告。教师可以查看报告的核对入口。
4. 获准教师在本次报告中回听片段，并分别确认学生声音、噪声、削波、缺音和重叠。选项默认不确定；明确发现缺陷的片段不能被改为无缺陷。准确短参考可选，最多 30 字，必须听原音确认，不自动采用 ASR 文本。
5. M4 保存独立核对记录并重新入队音频分支，复用成功文本结果。核对过且质量合格的片段才送腾讯：无短参考为自由说；独立确认的短参考为句子模式。每次外呼、发送和写回仍检查授权、来源与租约。
6. 任务完成后双端查看实际指标、词级候选、有效声调 / 音素和原音。没有有效时间或声调字段时保持未知；自然对话模式不被扩充为逐字声调诊断。没有校准的服务分数不映射等级，也不直接按阈值判错。学生撤回录音时删除音频、核对记录和派生结果，并清理当前页面回听缓存。

## M4 数据与权限

- SQLite migration 7 新增 `audio_reviews`。核对记录包含授权教师、关系 / 权限代次、提交、封口清单 hash、原始元数据 hash、字节 hash、版本、声明依据和到期时间。
- 核对记录的依据明确为 `teacher_listening_declaration`。它不重写原始 speaker / quality，不证明自动识别或专业声学判断正确；来源不明或质量不确定的片段不送评。
- 只有本次作业的授权教师能提交核对。老师和学生只能回听自己有权访问的提交。浏览器没有文件路径或供应商密钥；回听以临时 WAV Blob 呈现。
- 活跃分析中禁止修改核对，防止抢占租约；来源变化后旧音频结果失效。教师关系撤销、原文 / 音频撤回、TTL、来源篡改与迟到结果都有独立检查。
- v4 已获准记录仍可按原用途读取和撤回；旧说明不能增加音频处理用途。旧页面须刷新到 v5 才能开始新的默认音频会话。
- 本轮后台最多 12 个评测片段，单片段保持既有 5 秒分段与总量上限；报告明确实际覆盖。后续大规模连续分批和自动声源 / 对齐仍按 AUD-02 / DR-06 继续完善。

## 本地启用

```dotenv
ASK_KAI_TA_TRANSCRIPT_ENABLED=1
ASK_KAI_TA_REPORT_TEXT_PROVIDER=minimax
ASK_KAI_TA_REPORT_TEXT_MODEL=MiniMax-M3
ASK_KAI_TA_REPORT_EXTERNAL_REVIEWED=1
ASK_KAI_TA_AUDIO_EXPERIMENT=1
ASK_KAI_PRONUNCIATION_PROVIDER=tencent_soe_v2
ASK_KAI_TA_AUDIO_REVIEW_ENABLED=1
# Tencent 三项密钥只在本地环境配置，不提交 Git。
# ASK_KAI_TA_AUDIO_ASSESSMENT_VALIDATED 保持未设置；本轮不宣称通过声学验收。
```

`ASK_KAI_TA_AUDIO_REVIEW_ENABLED` 只允许带有效逐片段核对证据的外呼，不是绕过 speaker / quality 的开关。后续真实学生试点仍需正式授权和机构的数据处理安排，本机 Mock 教师选择不代表这些事项已验收。

## 已验与未验

- 已验：合成 PCM、本地 Mock M4、实际腾讯适配器连接本地模拟 WebSocket，验证默认采集、未核对不发音频、授权回听、逐项核对、来源绑定、后台重新评测、复用文本、双端结果、删除及手机布局。测试入口为 `npm run test:teacher:audio:browser`。
- 已验：腾讯真实连接与签名握手返回 `code=0`，未上传音频；这不等于真实音频评测成功，也不证明配额、模式输出或声学质量。
- 未验：作者 / 真人麦克风录音的真实腾讯结果、普通入口真实供应商全链路、自动说话人 / 回声 / 质量判定、真实文本对齐、专业发音教学准确性。AUD-01 / 02 / 04 保持未完成。
- 验证日志与截图只含合成材料，位于忽略的 `.local/audio-assessment-checks/`；不提交真实学习者录音、文本或原始供应商报文。
