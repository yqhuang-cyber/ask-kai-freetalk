# Ask Kai Agent 完整交付任务清单

2026-10-15 · 规划，未开始新增实现。依据当前 README、implementation-plan、PRD 与运行代码；用户已确认指当前 Ask Kai Web Agent，不新增 WhatsApp 渠道。

## 1. 最终目标与范围

三个入口（Mission Call、主题对话、自由聊天）能够根据不同学习者的当前意愿、相关能力和近期表现，完成自然、简短、可调整的语音对话；计划能影响实际行动，实际反馈能影响后续行动，总结忠于证据，并通过独立质量与设备验收。

本次仍为独立 Web POC、真实豆包全双工、本地 mock HSKai。四位虚构成年学习者是能力差异的测试背景，不代表完整 HSK1～7 教学能力，也不代表儿童上线验收。先完成有限运动主题及授权 Mission；自由聊天允许零教学目标。外部 HSKai、生产持久化、专业发音评分、多主题后台、正式部署另列。

动态 Planner 最新实施顺序以 [TP-00～11](topic-planner-tasking.md)及[独立主题管理服务设计](topic-management-service-design.md)为准：主题管理端提前由 LLM 生成、准入并发布 TopicPack，学习端只读发布版本，cache miss 不生成；先运动、再第二主题验证，随后复用至 Mission／free。[DP 清单](dynamic-planning-tasking.md)保留执行门控职责，[IP 教学决策设计](initial-planner-teaching-design.md)保留设计依据。本清单补齐各模块及跨模块交付，不重复正在实施的 TP 工作。逐轮端到端总预算目标最多 2 秒，预算代码正有工作区改动，真实达标仍待验证。评测独立跟踪 [Agent 评测计划](agent-evaluation-plan.md)。

## 5. 这次 tasking 的完成标准

1. 三入口 × 四类合成背景均有完整新版本对话证据；不同需要可适配，相同需要允许相同策略，不按姓名／HSK 固定映射。
2. Mission 承接授权内容，主题围绕当前选择，free 普通交流允许零教学；学生换题、拒绝、求助、打断和结束均有效。
3. 首轮与后续实际回复难度、语言支持、追问及纠错通过校准评测；不只看计划字段。
4. 本轮受控目标须有正式生成因果证据；advisory 结果单独报告。门控未证实不能宣布完整受控闭环完成。
5. 学习总结、反馈与自愿 mock 写回有来源；未校准语义／提示／独立／掌握保持未知，不能因想做完而补造证据。
6. 独立评测计划的工程、真实 provider、浏览器音频和安全门槛分别通过，必要失败／复核／缺口无悬空；生产发布要求仍保持独立。

本次只交付任务与评测规划，没有新增运行行为、模型请求、真实 provider 或设备验收结果。
