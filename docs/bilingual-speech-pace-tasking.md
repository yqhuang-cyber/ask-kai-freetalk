# 原生 S2S 中英文差异化语速：下一轮 Spike 任务清单

2026-10-25。状态：本轮实验与汇总完成，未找到达到筛查门槛的候选，BP-06／07 未触发。结果与分层证据见[第三轮实验记录](bilingual-speech-pace-experiment-results.md)；生产 Agent 未修改。

实验代码、配置、辅助函数和测试统一收纳于 [scripts/bilingual-speech-pace/](../scripts/bilingual-speech-pace/README.md)，入口与运行方法见该目录说明。

## 目标与约束

保持豆包原生实时 Speech-to-Speech 与全双工。当前会话的基础速度继续有效，中文在此基础上额外舒缓，英文不额外放慢；同一回复内切换语言时也应体现差异。

本轮优先寻找可重复的声音效果，不以文案更合理或模型口头确认代替验收。输出路径不增加文本生成、语言分段再合成或浏览器变速步骤。教学内容、语言支架比例与语速分别观察，不将少说中文、增加静音或重复词句算作中文发音变慢。

已有证据：[第一轮参数与提示词实验](bilingual-speech-pace-spike.md)、[第二轮 Tutor 身份实验](bilingual-tutor-prompt-spike.md)。第二轮有 34 条固定内容样本通过严格核对，但未观察到预期效果；自然问答与口头请求的证据不足。新实验单独编号、保存条件和评分规则，不重新判定旧样本。

## BP-01 的具体检查

1. 用已知作者文本定位 ASR 偏差：同义表达、同音字、句子遗漏或话轮切分分别记录；同时检查音频首尾、采样格式、实时发送节奏和输入归属。
2. 针对新实验，事先登记允许的同义表达和关键意图检查。作者请求中的语言对象、慢／快方向、否定及“只改中文／英文不变”等范围必须一致。单纯出现几个关键词不等于完整意图正确。
3. 无关措辞差异可以按预登记规则接受；关键语义不能确认时标为无效。规则在采集前固定，不根据输出好坏修改。
4. 准备短作者材料与盲听编号。可在已忽略的 `.local/` 保留少量本机作者生成的输入和输出音频供听音；代码库只保存作者脚本、哈希、统计和结论。真实学习者数据不进入实验。
5. 采集关联到明确输入和回复的音频。混合输出的语言边界由实际听音或经核验的对齐结果确定，不能从文字分片与音频分片的网络时间猜测。

如需查看作者输入对应的 ASR 来诊断，限定在本机临时处理，最终只保留错误分类和脱敏统计；不提交原始供应商事件或转写。

## 暂定效果标准

以下是下一轮筛查门槛，尚未获得产品验收；开始采集前固定版本。

- **中文**：同内容、同音色、同基础速度下，发声速率相对基线降低至少 15%，并听出自然舒缓。仅延长开头、结尾或句间静音不算通过。
- **英文**：速率尽量保持在对应基线的 ±10% 内；若基线自身波动已经超过该范围，先补足基线并标为不确定，不从单个样本判断效果。
- **重复性**：有信号的候选需要至少 3 个新会话复验，其中至少 2 场同时满足中文与英文门槛；这是小样本筛查，不是统计显著性或供应商保证。
- **自然度与内容**：不出现逐字蹦读、异常拖音、无关重复、漏词或通过改变内容制造时长差异。自然问答中的字／词速率只作辅助观察。
- **混合与持续性**：混合回复按实际语言段核对；多轮实验记录后续至少 3 轮，不能只评估紧接调速请求的一句。
- **响应及时性**：保留原生链路，记录输入结束至首个实际音频数据到达的客户端时延，与同批基线并列；音频 started 事件单列。明显退化单独调查，不将文本先到当作声音已到。

先比较同一语言相对自身的基线，不直接比较汉字／秒与英文单词／秒。基础 speed=0 与 -20 各自建立基线，不能混在一起计算。

## 规模与停止条件

先做短样本筛查，按不超过 12 条目标回复的小批次检查结果；每次 live 调用沿用现有 480 秒与每段最多 40 秒输出的上限。上表数量是各任务的初始规模，不代表一次性全部执行，BP-06／07 的后续数量在候选确定后登记。

- 输入关键意图、音频完整性或归属无法确认时，先修评测入口，不继续累积不可判定样本。
- 接连两批没有方向一致的信号时，记录该路线当前结果，切换下一项预登记方向，不无限追加同义提示词。
- 达到音色初筛范围后仍无信号，交付当前边界和剩余未知项；结论限定为本次配置与样本，不宣称原生 S2S 原理上不可能。
- 提示词效果有信号后，先完成重复性、混合语言和完整上下文复验，再讨论正式接入。

## 交付与验证边界

每批记录模型、音色、基础速度、提示词／输入哈希、样本有效性、PCM 与发声区间统计、首包时延、听音标注和失效原因。声音效果、网络时延、教学内容质量分别描述。

探针运行时或合同有修改，按仓库要求运行 `npm run verify` 与 `npm run replay`。工程／synthetic、真实供应商、浏览器播放／人工听音三类检查分开报告。Mock HSKai 身份与记录、播放回执、配置 ACK 均不能证明人已听到或语言节奏达标。

预期落点：扩展现有独立探针、作者候选集与结果文档；不改真实学习者画像、不触发外部 HSKai 集成。本清单本身只增加 Markdown 文档，无运行时改动。
