2026-10-11 已按用户要求将完整评测文件纳入 [V3.1 版本目录](eval-datasets/freechat-v3.1/)：[Excel 工作簿](eval-datasets/freechat-v3.1/ask-kai-freechat-eval-v3.1.xlsx)、[规范 JSON](eval-datasets/freechat-v3.1/ask-kai-freechat-eval-v3.1.json)、[48 列 CSV](eval-datasets/freechat-v3.1/ask-kai-freechat-eval-v3.1.csv)及[优化说明](eval-datasets/freechat-v3.1/review.md)。这些是用户提供的固定案例脚本、参考与评审标注，未采集真实供应商逐字稿或录音；不包含真实模型执行结果。[版本清单](freechat-eval-manifest.json)记录文件路径、大小及 SHA-256，原始来源 SHA-256 与本次文件校验值分别保留。

## 完善内容

- 每案补齐开场事实、首轮推断的软目标、初始状态、未知信息及证据来源。软目标可改变，不是强制课程任务。031、034 不从第二轮倒推初始主题，033 不凭参考回复制造初始猫兴趣。
- 初始完整画像、历史会话、`known_items/new_items` 未提供，显式保留 unknown。007、015、016 仅根据首轮已知语言标注声明最小场景假设；它们是测试条件，不是真实授权画像或掌握证明。
- 每轮保留原始用户输入和参考回复，另列规范必须满足、禁止行为、关键失败、语言支架、主动承接与总结范围。原始 CSV 的 20 列逐格保留；V3.0 增加 20 个规范字段，V3.1 再增加 8 个审阅字段。工作簿保留 12 个有效原始列。
- 244 轮新增独立 `language_ground_truth`、映射十维的检查点、0/1/2 锚点、简短候选参考与合理替代；33 个关键回合补具体评分对照。候选不是实际模型输出，只有 007 第 3 轮精确输出不接受附加内容。
- 语言预期由独立语义标注定义，只使用初始声明条件和截至本轮的学生输入。普通正确中文、参考回复或未来回合不构成掌握证据。案例 037 的茶已知自述只能从第 11 轮使用。原生产代码预览仅为诊断，不能反过来定义正确答案。
- 回放历史只包含实际此前 Kai 回复与学生输入。参考回复用于评审，不能作为待测模型前文或实际输出。固定学生脚本测试特定上下文行为，不是实际自然互动的完整记录。

## 与当前策略对齐

继续使用 `kai-content-v3` 的原十维、0/1/2 和权重。原五维的 9 条 `learning_guidance N/A` 不直接映射成十维豁免。纯社交的 progress 评自然承接、尊重只聊天或结束，不因“没教学”扣分。本集无预设十维 N/A，安全门槛不变。

中文优先，未知画像默认必要短英文；adaptive 只允许已知或易懂部分省英文，新表达仍要必要支持。精确单句输出请求仅约束该轮。共享 `kai-reply-v2` 预算不变：最多两句中文及必要英文，36 汉字、24 英文词、48 合计单位、180 字符，一个主要问题／任务、一个新点和一个短例。

40 个结尾已统一为短口头收束与现有 Web 总结。拼音长词表、任意新词卡和未知初始内容的“新学／复习”标签不作为当前 POC 的硬要求。总结只能引用实际发生且有来源的内容；没有受支持的卡片或练习证据时如实显示交流小结，不生成虚构成果。

V3.1 为 40 案分别定义 `summary_contract`：候选表达只有实际呈现或尝试后才纳入，学生事实保留来源轮次及角色／早餐等作用范围，不要求清单全出现。8 组声明的合成语言对照覆盖未知、初学者、能理解、明确只中文、明确双语、新表达帮助和恢复自动；这些对照不改变原案例初始未知信息。244 个主集及 11 个对照新示例均通过表面预算检查，这不证明真实生成或语义评分合格。

固定学生脚本补 `context_dependency`。依赖前轮内容未在实际模型前文出现时，先记录最早偏离，对该依赖标 `context_mismatch`，继续独立安全／指令检查；不填参考答案，也不把同一偏离的连锁后果重复计为多个独立缺陷。没有有效覆盖的案例不得宣称完整通过。

34 个主动承接信号都来自学生话语，不是真实 idle、沉默或定时器事件。听辨／发音案例没有实际音频，不能报告实听成绩，也不能把本集缺音频说成整个产品不支持语音。

## 检查结果与使用

编号、轮次、原文保留、目标来源、前文边界、初始假设来源、语言状态和评分版本均已检查。现有计数器对参考文本提示 27 条超预算、62 条语言表面提示、5 条问题数提示；这些类别可重叠，只针对作者参考文本。

67 条语言／问题数提示已逐条复核并附处理。中文词嵌入英译、引语、同一个问题的选项可能是计数提示；同时问形式与主题则已改为一次一个问题。不能把这些提示当作真实模型成绩，或用标点计数证明翻译、新点和任务语义合格。

```bash
npm run eval:dataset:check -- docs/eval-datasets/freechat-v3.1/ask-kai-freechat-eval-v3.1.json
```

在仓库根目录运行；CI 同样执行该检查。准备格式 v2 校验不发网络请求、不生成回复、不打分，仍兼容 v1。它检查重复／断号、原文一致、参考／未来前文泄漏、未知画像来源、诊断状态重算、独立预期与锚点完整、评分漂移和伪造执行结果。独立预期可与诊断预览不同，不为通过检查而改成生产代码输出。当前 JSON 不能直接交给 `eval:content`，也不能整份发送给待测模型。使用下方运行器收集实际回复后，仍需适配原十维评测器并记录人工／Judge 版本。

2026-10-11 已实现[真实多轮运行器](multiturn-eval.md)：`npm run eval:multiturn` 默认离线预检；显式 `--live` 使用固定学生音频经现有授权网关、ASR、教学和总结链路收集实际回复，保存提交、数据集、模型与策略版本。每案独立会话，参考不注入前文。输入音频可另用同一豆包 Key 合成并明确标记。工程模拟测试已通过，本评测集真实采集尚未执行；观测结果适配原十维评分和人工／Judge 复核仍是后续任务。

本轮完成数据准备。真实语速、插话、字幕播放、听辨及发音仍属于真实音频和设备验收；这 40 案例不覆盖全部三个入口的产品验收。
