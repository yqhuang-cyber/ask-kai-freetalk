## 分层验证

- **工程与合成**：完整 `npm run verify` 849/849；三个 synthetic replay；原中英 8 个冻结文件 hash 未变。原中英正常浏览器回归和中泰正常浏览器回归均通过。
- **合成浏览器故障注入**：9 类 × 3 轮，27/27。包含结束早于 ready、结束发生在麦克风授权等待期间、重复结束、音频关闭等待、换人、连续重连和旧消息、取消准备及迟到结果、产品拒绝合成就绪、安全提示和 Mock 回执。输入设备为 Chromium 合成设备，不是人类麦克风。
- **真实 Provider**：6 个独立会话共 15 个完整回复。修正前两场与修正后四场分别保留；使用作者系统 TTS 输入，没有真人音频。此次均收到完成事件，没有复现之前的等待完成超时；不能据此宣布历史问题已根治。
- **真实自然聊天**：修正后两场，每场两轮，4 轮均有中泰文字与音频。一次输入 final 不完全匹配作者句，不能算真实意图准确率。
- **真实语言切换**：修正后两场，3 轮流程均完成，但两次最后的词义求助仍只有中文。控制句均出现同音字或漏词等 ASR 差异，没有得到可验证的精确本轮控制输入，不把它们算作完整作用范围验收通过。
- **规划模型**：修正后四场中，2 场初始 MiniMax 提案通过，2 场校验失败后使用规则计划；降级是已实现的保底，不计为模型自适应成功。
- **真人与泰语质量**：未做真人麦克风、母语者听感、自然度和翻译等义验收。

## 仍开放的问题

1. S2S 的实际听觉响应与 ASR final 存在差异。此次作者请求里的“只”被识别为同音字，“泰语”等词也出现错字或漏词；模型能按声音临时切中文，宿主却没有得到同等明确的文字控制。**没有为了通过测试而全局做同音替换或把模糊请求永久写入偏好。**
2. 中泰恢复依旧不稳定。即使宿主状态是 required，模型也可能延续只中文。修复指令矛盾不能证明模型已稳定遵循。界面保留实验提示；后续需补真实有效控制样本并独立验证模型 / 多语种替代路径。
3. 此次未重现历史完成超时。探针已增加供应商事件计数、内部事件计数、结束时状态，以及断线 / 取消 / 提前结束的明确分类；仅记录汇总，不落原始 wire trace，不能把无身份的 usage `response.done` 认作某个回复完成。
