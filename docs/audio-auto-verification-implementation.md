# 作业录音自动核验：本地实施记录

日期：2026-10-28。分支：`codex/report-analysis`。范围：[AV-01～07](audio-auto-verification-tasking.md) 的本地工程链路。用户确认先完成链路，腾讯真实接口检查可以滞后。

## 当前行为

学生开始一次新练习前，说明文本 / 录音保存及 MiniMax、腾讯 ASR、智聆用途。提交后，M4 的文字分析与音频分支并行；页面只展示处理进度，全部收束后发布深入报告。音频分支自动执行：

1. 核验本次获准麦克风采集、样本时钟和播放状态，保留缺口和重叠证据。
2. 测量静音、音量、削波及估算信噪比；重组连续的存储块，保留原始 PCM。
3. 将选中的候选语音交给腾讯录音文件识别，持久保存任务号后释放执行租约，稍后继续查询。
4. 用词句时间戳及说话人线索检查可用性。来源 / 质量不确定、多说话人、缺口或播放重叠等保留未评。
5. 可用句段自动进智聆：没有独立短句参考时自由说；实时转写与离线识别独立一致时形成 `auto_aligned` 短句候选。机器参考不是人工核准或绝对正确答案。
6. 保存实际测量、引用范围、未评覆盖和原因；收束并发布深入报告。

老师正常零点击。可选查看最多六条核验疑点、回听与人工修正；人工证据版本化保存，不能改写原始录音。单次录音全部不可用、识别未开通或持续失败，也会发布已有的理解 / 表达分析，并明确音频未评，不再无限等老师。

启用自动模式后，历史“等老师核对”的报告也可展示已有文本结果。旧录音未获得新的 ASR 用途，不自动送识别；新功能应使用刷新后新建的练习。

## 数据和执行边界

- 本地 Mock HSKai 的 M4 是唯一业务数据写入者，SQLite migration 8 新增 `audio_units`、`audio_auto_checks`。分析服务独立运行，实时语音不等待报告。
- `homework-mic-v1` 逐帧封装样本序号、AEC 设置和实际播放状态。网关先验证单调时钟、剥离头部，再向豆包发送原来的 640 字节 PCM；FreeTalk 默认协议不变。AEC 开启不等于证明无回声。
- 原始传输 / 保存块仍最多 5 秒，增加约 200ms 前缓冲、400ms 静音尾。只重组同源且样本连续的块，最长 30 秒；容量截断和真正缺口不会拼成完整话句。Kai 开始播放前若已有静音尾，先封口，避免把回复误装进上一句。
- 派生单位保存原片段引用、字节 / 元数据 hash、范围和 manifest。送识别 / 评测前重新校验原音，不保存一份不可追溯的替换音轨。
- 本轮均匀选取最多 12 个语音单位。一个单位含多句时，按离线时间戳选取一条中文句子，保留约 100ms 边缘；报告注明其余句子未评。未采用片段不被当作能力差。
- 每次执行最多处理三个 ASR 提交 / 查询；等待时持久化并让出任务，通常两秒后再查询。安全的查询失败最多三次，退避 4 / 8 秒等；单次识别准入十分钟截止。上传受理状态未知时不盲目重传，显式重试才重新尝试。
- ASR 的 uint64 任务号按字符串保存，查询时作为原样整数发出，避免 JavaScript 精度丢失。关闭前 / 崩溃后依靠 M4 记录恢复，无需保持浏览器连接。
- 智聆成功片段逐一检查点保存；后续超时 / 失败 / 显式重试复用成功 ASR 和测量，不重跑完整文字分析。
- ASR 本身是对音频执行的模型识别；MiniMax 的文本分析不冒充听音频。时钟、能量和削波检查是测量规则，不能代替真正声源 / 噪声校准。

## 授权与保留

新用途说明为 `deep-report-notice-v7`，单独记录 `audio.verification_processing=tencent_asr`。v4 / v5 / v6 仍按原用途可读、可撤回，配置变化不能给它们补充外发用途。

每次读音频、提交、查询、写回和报告查看检查当前拥有关系、权限代次、用途、TTL、源 hash 和任务租约。机器参考另绑定可读文本授权。撤回 / 到期删除原音、识别文本、外部任务引用、机器参考和核验 / 评测衍生结果，迟到结果不能写回。真人声纹注册未加入此 POC。

## 本地配置

在既有文本、录音实验及智聆配置之外：

```dotenv
ASK_KAI_TA_AUDIO_VERIFY_PROVIDER=tencent_asr
# 可选独立腾讯 ASR 凭据；默认使用已配置的 SOE SecretId / SecretKey。
# TENCENT_ASR_SECRET_ID=
# TENCENT_ASR_SECRET_KEY=
# TENCENT_ASR_ENGINE=16k_zh_en
# TENCENT_ASR_REGION=ap-shanghai
```

腾讯“语音识别 → 录音文件识别”与智聆是独立服务，需要另行开通。当前账号的既有检查返回 `FailedOperation.UserNotRegistered`；已映射为 `asr_not_enabled`，不再记为笼统失败。按用户要求，不继续做真实接口检查。开通后的真实端到端联调另做。

本机已配置自动模式，但没有修改 `ASK_KAI_TA_AUDIO_ASSESSMENT_VALIDATED`。自动模式目前只支持实验性的“待核对候选测量”，不证明声纹身份、无噪声或发音教学准确性。实际使用页面保留这一限制；不映射等级，不从文本推断音素 / 声调。

- 新增契约检查覆盖：帧封装、重放拒绝、采集缺口、静音边界、合并块来源、未知不伪装为人工核准、多说话人 / 语言 / 时间戳、旧用途不可升级、十分钟收束、撤回 / TTL / 迟到结果、退避、来源篡改、成功片段复用及真实 SQLite 重启。
