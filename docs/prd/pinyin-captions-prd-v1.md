# Kai 中文字幕拼音 PRD v1

日期：2026-10-26。状态：普通 Web／Gateway 首版已实现，供本地 UI 试用；真实浏览器与真实语音的联合人工听感尚未验收。背景见[Spike](../pinyin-captions-spike.md)，实现及分层验证见[实施记录](../pinyin-captions-implementation.md)。

## 目标与默认规则

Kai 回复中的中文默认显示带声调拼音，汉字上方小号注释；中英混合时只为中文注音。拼音不送入语音合成、不增加一句朗读，不要求实时模型先生成完整文本再合成。中文、英文、标点、数字和换行的原文保持。

每场新对话默认显示，学习者口头说“关闭拼音”后，当前及本场后续字幕隐藏拼音、保留正文；说“打开拼音”或“重新打开拼音”可恢复。设置不保存到学习者画像，结束、换人或重建会话后恢复默认。

页面提供“显示拼音”复选框，与本场语音设置共用实际状态，便于直接比较。开聊前显示明确标注的字幕效果示例；示例不冒充 Kai 实际回复。示例开关供预览比较，开聊时依默认规则重置。字幕字号同时作用正文和注音；关闭全部字幕时拼音一同隐藏。

## 语音控制首版范围

明确命令在安全检查后、已接受的 ASR final 上识别，不在 partial、Kai 输出或 Planner 提案上执行。支持“关闭拼音”“把字幕拼音关掉”“不要显示拼音”“打开拼音”“重新打开拼音”等明确单独命令，以及有限英文 hide／show／turn off／turn on pinyin 表达。

“不要关闭拼音”、引用命令、询问命令词义、同时要求相反设置、其他字幕设置，不触发拼音切换。混合命令如“关闭拼音，再解释银行”首版交给正常对话、不自动切换，不能声称已执行；自然表达扩展／原生 FC 继续保留为后续方案。界面提示用户可使用明确命令。

## 完整执行流程

1. 接受有效命令，绑定实际会话、输入话轮、请求 ID 和单调 revision。
2. 向当前 Web 发送目标布尔设置；Web 只处理本会话及最新版本。
3. Web 重绘当前可见字幕，只改变注音；正文和后续播放时间不变。开启时先确认注音依赖可用；失败继续显示原文。
4. 页面 ACK 必须精确匹配 session／request／revision／目标值；配置 ACK、模拟数据或一句确认语不能代替页面回执。
5. 正常自动确认被隔离，等待原回复终止与页面应用成功后，宿主通过既有固定语音通道播报一次简短确认。需要英文支架时附短英文。
6. 播放完成按真实回复编号及 PCM／字幕完成边界确认；随后完整上下文记录已确认状态，与语速／课件／教学设置共存。

手动开关也走同一设置／回执链路，但不伪造语音输入、不额外播报。重复设置幂等到相同状态；晚到旧回执不产生确认。普通插话取消旧口头确认，不回滚已接受的页面设置；新设置用更新版本替换旧目标。

## 边界与降级

- 使用词典原调，拼音是阅读辅助，不是供应商实际发音、逐字时间戳或发音评测；多音字、姓名、稀有字需后续质量完善。
- 注音依赖或转换失败时降级原文，语音继续；页面应用未确认时不播报成功。
- 拼音不加入原始回复、观测正文、学习记录或播放字符计数；设置指令不产生学习尝试。
- 保留渐进短语和当前短语高亮，同一可见上下文统一转换，避免高亮边界拆散词语；异步加载不复活已结束回复。
- 不扩大 Slides 工具权限，不持久化偏好，不增加独立意图 LLM。

## 验收

默认显示、手动关闭／恢复、本场后续回复继承、语音关闭／恢复及一次结果确认、关闭全部字幕、新会话复位、异步旧回执隔离与失败降级均需覆盖。课件、调速、收尾和旧计划竞争保持回归。

合同／合成回放、真实供应商、真实浏览器／音频、真人听感分别报告。当前首版提供 UI 试用，不把有限词语样本或合成音频检查写成完整教学质量验收。
