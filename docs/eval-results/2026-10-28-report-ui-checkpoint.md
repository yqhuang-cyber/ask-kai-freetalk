# 对话报告与师生界面提交检查点

日期：2026-10-28。分支：`codex/report-analysis`。

## 本次改动

- 新会话默认记录文本，明确提交后由 M4 独立 Worker 分析。学生在报告完成前查看进度，失败后可重试，不以基础规则记录替代深入报告。旧会话缺失的文本或音频不会补造。
- 增加真实任务驱动的分析进度：文本分析、修复、引用检查、录音核对、音频评测与报告生成；进度绑定来源、调用和租约。分析超时、服务失败、输出拒绝分别显示，修复请求有独立预算且受总时限约束。
- 补齐 POC 录音评测链路：新说明和核对模式下自动采集，授权教师回听并核对声源、质量及可选短参考后，合格片段才送腾讯适配器；双端显示音频指标、候选与原音。撤回或过期时清理相关派生结果。
- 学生端分开待练习、当前练习和分页历史报告，压缩说明并突出练习入口。教师端采用备课与作业并列布局，显示核对及发布步骤，折叠旧草案和详细说明。
- 教师端关键字段、操作及状态采用中文在前、简短英文辅助；教学内容保留原文。

## 提交前验证

- `npm run verify`：789 / 789 通过。
- `npm run replay`：normal / interruption / failure 三类合成回放通过。
- `npm run test:teacher:browser`、`npm run test:teacher:planning:browser`、`npm run test:teacher:report:browser`、`npm run test:teacher:audio:browser`：全部通过。浏览器依赖、麦克风及模型均为合成测试；音频专项连接本地腾讯模拟 WebSocket。
- 桌面、平板与手机布局通过相关检查；浏览器页面错误为 0。检查产物保存在忽略的 `.local/`，不进入提交。
- 候选源码与文档未检出本地环境密钥；本地配置、真实教学数据、音频、数据库及 `.DS_Store` 不进入提交。

## 保留边界

本轮提交检查未调用真实供应商，未做真人麦克风或播放听感验收。此前腾讯真实签名握手成功只证明连接，不代表音频评测成功。人工回听核对不证明自动声源识别、文本对齐或专业声学判断正确；真实发音效果和教学质量验收仍未完成，整个报告 feature 不标记全部完成。业务数据仍使用本地 Mock HSKai。
