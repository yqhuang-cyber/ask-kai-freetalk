## 校准了什么

| 校准 | 实际例子 | 本次处理 |

| 自然聊天不强制指定下一问题 | 006-t09 合理提出轻松话题；010-t06 短肯定；016-t04 等待思考；010-t12、016-t08 未按模板追问 | 接纳相关承接和耐心等待，不用作者后续脚本强制乐器、电影同伴或书籍语言问题。原要求保留，校准理由逐项记录。 |
| 听力 fixture 与运行能力分开 | 012-t01、034-t01/t02、040-t01/t02 的“本回放无声音”前提 | 缺客户端播放／隐藏字幕证据，相关 7 项置 null。没有音频消费证据不等于内容已失败，也不等于听力通过。 |

## 评测工具改动与使用

- `review-calibration.js` 只由评测路径使用，定义版本化复核口径；每个低分和 null 都需分类，不可评分类必须为 null。ASR 复核证据只允许当前／此前学生文本，禁止以当前 Kai 回复作为语义恢复依据。
- 评分器现在拒绝总结引用未采集轮次、可用记录存在却没有证据引用、以及没有真实总结却给总结打分。总结单列 source fidelity 与 empty-learning coverage。
- `eval:review:compare` 在同一个不可变输入上验证前后两版评分，输出维度、逐项、ASR、状态及总结差异。原 v1 文件不覆盖。
- 可选模型 Judge 的评审指令同步校准；本次没有调用它，新的判断也不能代替人工批准。

```bash
npm run eval:review:compare -- \
  --input .local/combined-scoring-input.json \
  --before .local/combined-assisted-judgements.json \
  --after .local/task01/calibrated-judgements.json \
  --out .local/task01/review-comparison
```
