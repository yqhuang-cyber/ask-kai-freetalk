031 的失败诊断确认固定脚本 TTS 有一个 69,632 字节 PCM 包，超过生产单包 64 KiB。评测输入侧 `authored-tts-pcm-reframing-v1` 保持 PCM 样本、顺序、所有权，仅拆包后通过冻结解码器；Agent 输出解码不变。其余初始 TTS 失败缺少同样粒度诊断，不能全部归为这一原因。

011 第 6 轮两次观测到 transcription.started，但无 delta、final 或回复，45 秒后终止。可能涉及短语气词的输入合成、VAD 或供应商处理，**根因未确认**。保留原 `Hmm.`，不改成别的学生发言来制造完成。终止时现有 summary 的 ended/partial=false 也不能覆盖采集层的 5/16 实际分母。

## 根因假设与后续修改面

以下是待验证的设计候选，本轮没有实施 Agent 修改。先完成高影响记录人工复核和最小对照，再确定改动。

| 顺序 | 假设与修改候选 | 需要的辨别实验／回归 |
| --- | --- | --- |
| 1：继续评测工程 | 011 的短语气词停顿与 036／040 的输入归属存在采集或供应商边界问题 | 分开检查 authored TTS 时长／能量、完整 PCM 发送时间、首个 ASR final、残段和回复结束时间。固定同一输入做小范围重现；不改文字、补参考或将运行器等待效果当 Agent 改进。 |
| 2：Agent harness 时序 | 当前决策在本轮音频回复开始后更新，动态只中文、拒绝或换题可能未及时生效 | 先对比相同选择放初始画像 vs 当前发言、第一轮 vs 第二轮；确认 context/version/response 时序。再设计可确认的本轮策略应用或供应商原生控制。检验语言 08、006-t11 与未受影响对照；不能仅凭 244 个 timing 标记直接改提示词。 |
| 3：口语收束与密度 | 模型把总结请求解释为口头完整清单；共享规则缺少稳定的结束路径 | 对照短口头告别／一句回顾与单独 Web 结构化卡片。回归 19 个超预算终轮及 027／035 的结束后邀请，并确保用户请求拼音仍能在可视内容中得到满足。 |
| 4：澄清与语言支架 | 默认补全歧义，容易把罗马音当英文支持；已知承接仍机械双语 | 优先三类歧义 029／030／033 和语言 01–08；用语义等价而非逐句字符串作为要求。区分澄清一个选择、已知承接、新表达、没听懂、只中文的范围。 |
| 5：纠正与来源 | 过于积极的纠正、兴趣与所有权／掌握推断、new/review 来源不足 | 人工先复核 018-t02 和 007-t02；设计基于当前实际表达和来源的纠正／标签保护。回归自然变体、明确已知、复制、自述、角色事实及真正错误，避免不纠错也算成功。 |
| 6：有来源的总结投影 | 有真实教学但缺目标事件，现有有限运动规则输出空态 | 定义“模型提出”“学生尝试”“学生声明已知”三个有来源的记录范围；先覆盖本集出现的少数主题，保留空态与部分态。不得把词出现次数变成掌握或发音成绩。 |

评测也需改进：先抽查所有 36 个失败轮、关键失败和 42 个 ASR 偏离，再校准部分满足的边界；听力案例 012／034／040 的作者“无音频”语境与实际音频传输能力需区分，收到模型 PCM 不证明学生完成播放或隐藏文本听辨；新增 mock 只读审计后才能判断内部持久化要求。若更新标注或 Judge，另立版本并重评同一原始观测，不覆盖这次基线。
