- TA-12 子集：有界问答、跨主题组织形式、帮助与覆盖记录；去重、会话 / 回复归属、封口与截断。

- 默认确定性作者规则，版本为 `dining-analysis-v2`。点餐支持食物 / 口味 / 数量问答、请求意图、份量、口味、同轮组织及跨轮再次使用。跨主题支持明确“因为”理由连接、先后叙述、重复 / 澄清请求的形式观察；不声称整体语法正确、通用语义诊断或已掌握。
- 提交前重算已准入分析并校验整份结果，拒绝即使来源哈希正确但分析被修改的报告。失败保留提交成功状态，可显式重试。
- 历史报告保留原版本，旧 fence 不补造问答；没有新增目标完成、长期掌握或等级写回。

## 关键反例

取消 / 未完成 / 截断回复、跨会话输出、旧轮回复迟到、引语和识别不确定、中间输入打断关联，均不生成听力结论。数量短答可以是情境问答观察，不能自动认定完整点单目标完成。

第六轮以后的目标仍可进入记录；超过保留上限标截断并声明仅限保留片段。重复输入不增加独立轮次；封口后的输入拒绝，返回快照副本的修改不影响已封口证据。

错误 response 来源、错误问答含义、同轮冒充后续回答、无完整表达的目标片段、篡改后的分析结论均拒绝。删除 / 授权变更仍使用原业务屏障，迟到结果不能复活已删除记录。

昆虫任务中的明确理由和澄清可以观察，但点餐表达不会变成其目标成果；建议来自当前已发布目标。学生 DTO 不含证据事件 ID、教师字段、等级或新增私有字段。

## 放行与未覆盖

完整 TA-12 的异步抽取、持久覆盖 / TTL，以及 TA-15 的通用语义分析与教师教学校准仍未完成。听力 LST-02 / LST-03、口语 SPK-02、音频 AUD-01 / AUD-02 独立排入下一阶段。新报告无需等待 TA-20 等级。
