# 对话内课件回看：第五阶段工程接入

日期：2026-10-26。结论：**VS-04～06 工程核心已经接入普通 Provider／Gateway／Web，默认关闭。基础原生闭环已跑通；完整质量矩阵及真人设备验收尚未完成。**

## 实现与边界

1. Provider 保留源 profile 的工具拒绝；只有显式会话能力开启受限工具家族。原生 FC 走独立 `ui.calls`，原调用结果通过 `sendUiResults` 返回，未制造 turn_id 或学习事件。结构非法批次执行前拒绝；同 call 重传只有一个等待者，参数冲突失败关闭。
2. `SlidesSession` 组合权限门控、`SlidesCoordinator` 和快照编译，授权及连接代次隔离。真实组件应用回执后才返回 applied；丢回执先核对，未知冻结，不盲目累计相对翻页。明确撤销仅取消未派发回看，立即废止旧工具代次；已接受、已派发事务按真实结果结算。
3. 普通 Web 加载固定作者课件、被动展示框和手动回看。初始第 1 页，无后续页入口。显式 Mock 作者演示选项可依次展示三页建立测试历史，页面明确说明来源，不能当成学习成果。
4. 工具结果不等待上下文 ACK；完整教学、课件、工具和语速配置串行更新，ACK 后才记为应用。页面可在旧配置等待期间继续确认，随后再编译最新状态。普通插话在工具等待期间只隔离旧语音 lane，保留页面动作；配置收束屏障不宣称原生 FC 来源已核验。
5. 展示框 5 秒未就绪时，降级到普通无工具语音；迟到的组件消息不重新开启能力。真正打开 Provider 时重新开始就绪预算。会话结束、权限撤销和安全限制隔离事务。新增诊断只含状态、页码、版本、队列及耗时，不记录原话、音频、原 call_id 或工具 token。

## 分层验证

| 层级 | 已观察结果 | 实际限制 |
| --- | --- | --- |
| Synthetic／合同 | `npm run verify` 617 项通过；其中新增 21 项普通 Provider／Session／Gateway 接入检查。`npm run replay` 三条回放符合预期终态，证据仍为 attempted | 给定调用与故障注入不能证明模型会正确理解所有表达 |
| 真实 Provider＋普通 Gateway | 固定作者语音三轮：3→2；请求第 3 页保持 2 且无工具调用；再回到 1。使用普通 HTTP Mock 授权、普通 Gateway 和 Provider | Viewer 回执为明确标记的 synthetic；没有真人麦克风。前置一次遗漏授权的票据失败未连接供应商，补齐后通过；两次后续代码修正均另复测通过，详见 JSON |
| 真实 IAB＋原生语音＋实际组件 | 隔离 HTTP 测试外壳，复用普通 Gateway／Provider、实际 SlidesViewer 和 AudioIO。最终三轮观察到 3→2、后续请求保持 2、再到 1；回复与页码一致，45 个输出片段排入浏览器播放并观察到队列播放完成；正常结束后控件关闭 | 作者录音代替麦克风，Mock 作者历史；不是普通 Web 含 Planner 的完整验收，也不是人耳听感证明。该浏览器宿主启动在最终握手降级／重传／完整指令哈希补丁之前，后续补丁由最终合成和 CLI 检查覆盖 |

21 项接入检查覆盖：默认开关／受限工具、组件初始化和授权绑定、错误／迟到回执、去重及原生重传、非法批次、音频持续上传、取消排队项、旧工具代次拒绝及新输入重启、关闭中的未知结果、握手失败降级、翻页与口头调速组合、配置等待时手动回看。既有教学与收尾回归同时通过。

浏览器共建立 3 次真实连接、送入 8 条固定作者录音。前两场分别检查 2 条和 3 条输入后，因测试期间停留过久触发测试宿主 180 秒上限，记录 SESSION_DURATION_LIMIT；最终一场 3 条完整执行并正常结束。不能将三场都记为正常完成，也不把第一次定位器等待超时误报成页面操作失败：随后可见真实组件已到第 2 页、回复完成、音频队列播放完。完整观察只使用固定作者内容，无真实学习者录音或转录。

## 运行与移植

普通 POC 仍默认关闭。显式演示：

```sh
ASK_KAI_SLIDES_CONTROL=true ASK_KAI_SLIDES_DEMO_HISTORY=true npm run poc
```

只开第一个选项时从第 1 页开始，尚无历史可回看；第二个只允许 Mock。它们不写长期画像，不新增真实课程推进引擎。关闭开关时保留普通聊天行为。实验脚本集中在 `scripts/voice-slides-control/`：`gateway-probe.js --live` 使用 synthetic Viewer；`gateway-viewer-fixture.js --live` 提供作者录音的真实组件检查页，均不注册为普通产品路由。

跨项目复用契约、权限内核、协调器和控制会话；替换目标项目自己的授权、语音 wire 和页面适配。具体接口与源文件见[技术方案](../voice-slides-control-design.md)。不要复制 Mock 资料、作者推进历史或本账号的供应商时序假设。

## 尚未完成的验收

- 普通 Web 中真人麦克风、实际设备听感、完整 Planner 与课件配置竞争。
- 真实浏览器下更新期间插话、工具等待时连续追加／改口／撤销、音频取消与结束的完整组合矩阵；本次基础三轮不替代此前独立协议实验。
- 更大样本的漏调用／误调用和反馈质量；同一有效工具代次内无法重建缺失的原始发言顺序，仍按宿主首次接收顺序处理。
- 首段确认音频实际播放与组件回执的完整时延分布；本次播放队列观测不能证明真人已听见或理解。

因此 VS-07／08 仍有待验部分，保持默认关闭。原 23 条独立实验不因本次三轮通过而追溯改成当前普通 Agent 的全套验收。密钥、作者音频、模型回应明细、原始供应商 trace 和截图只保留本地忽略目录；公开 JSON 仅含去敏结果及源码哈希。
