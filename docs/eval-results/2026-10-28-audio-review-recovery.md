# 教师录音核对入口与异常恢复

日期：2026-10-28。分支：`codex/report-analysis`。

## 问题与修复

- 学生等待核对时，教师原先仍看到“报告已生成”，入口折叠在报告末尾。现在教师作业卡显示“录音待核对 / Review audio”，以“核对录音并继续”进入报告顶部已展开的核对区域；待操作的进度不再归档成已完成。
- 教师快速从作业 A 切换到 B，A 的迟到响应可能覆盖 B。现在报告读取同时核对身份代次、导航代次、所选提交和请求序号；轮询与保存 / 重试后的回调只能刷新当前报告，不能重新打开已经离开的作业。
- 保存核对的回执丢失时，后台可能已经入队，而页面仍显示待核对。现在先读取本页核对清单，核对同一提交、封口清单、片段元数据、目标版本以及声音来源 / 质量 / 短参考是否一致。确认内容已保存才刷新处理进度，不重发核对写入。
- 查询也断网时保留填写内容，暂停再次保存，提供“核对保存状态”的只读恢复入口。确认未保存时允许人工重试；遇到来源或版本变化时要求重新读取。已保存但进度查询失败时只提供刷新进度，不再次提交核对。

- `npm run test:teacher:recovery:browser`：六项合成故障检查通过，覆盖迟到报告响应、保存回执丢失、离线读回、未送达请求重试、进度查询失败和离开后的迟到保存回调。检查使用本地 Mock M4；第二份报告使用明确的合成 UI 响应，写入操作始终落在真实 Mock 提交上。
- `npm run test:teacher:audio:browser`：教师入口显著、核对到本地腾讯模拟 WebSocket、复用文本结果及学生端无需刷新自动更新通过。
- `npm run test:teacher:report:browser`：历史导航、等待 / 失败重试、报告与撤回流程通过。

本轮未调用真实模型或腾讯服务，未使用真实学习者文本或录音。浏览器麦克风 / 音频为既有合成检查，真实发音效果和专业教学验收继续保留为未完成。检查产物位于忽略的 `.local/`，不进入提交。
