## 主要反例

- 100 轮非点餐文本、末尾窗口、重叠去重、超过 12 窗口的可见未处理范围；无引用 / 假原文、错快照、错误顺序和被打断的问题不发布为有效候选。
- 文本模型输出声学判断、等级 / 掌握等越界内容时拒绝；每窗口最多一次修复；超时不接受迟到模型结果。
- 本地保存选择不会因后来开启模型而获得外传用途；旧说明版本、错误租约和 call_id、被修改的来源以及未审查用途不能发起外呼 / 写回。
- 旧反馈和文本先完成时仍能查询 M4，慢音频不阻塞它们；撤回一个分支不取消另一个仍授权的分支。
- 删除 / TTL 清除新派生引文；提供方不配合取消也不能写回。音频封口后更改 speaker / quality 元数据被 hash 拒绝。
- 外呼状态未知时不自动重新请求；显式重试不重跑成功文本窗口 / 音频片段。另一个分支仍在外呼时重试被拒绝，不能抢走租约制造重复计费。
- 腾讯错 voice_id、服务未开通、断开、超时、空 final、无效分数 / 时间 / 声调、未确认参考或未知说话人不伪装成功；握手时撤权不发送 PCM。
