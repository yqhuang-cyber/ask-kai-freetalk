# VS-01 第四阶段：会话级动作与可撤销工具权限

2026-10-26。**找到可继续工程接入的受限方案；不再把取得供应商 FC 输入字段作为本功能唯一实现前提。普通 Agent 仍未接入或启用。** 本轮没有证明豆包新增了输入身份，也没有放松语音回复的原生话轮归属。

## 1. 方案变化

页面控制是当前授权会话中的独立操作事务，使用本连接的工具调用编号和宿主动作编号；语音仍按实际 question／response 身份隔离。没有原生来源证据时，不给操作伪造 turn_id，也不绑定最近一次 ASR。操作结果不成为学习证据。

每批受限工具使用宿主生成的独立名称。撤销或明确改口获准时，立即废止旧批次，取消尚未派发的回看；已经派发的动作仍核实结果。旧名称的未接受调用即使迟到也拒绝，旧 call_id 的重传只复用原事务，不再取消后来加入的新请求。

原结果和对应回复完成后，才注册新批次并等待配置确认；此后新开始且完成的语音输入才能开启新批次操作。在配置更新期间开始的输入不能由迟到 final 重新开启权限。这里的输入边界是新操作的准入条件，不是把某个 FC 宣称为该输入的原生事件。全程继续原生 S2S 与持续采音，不增加文本生成／分段合成或额外意图模型。

共享内核已放入 apps/realtime-gateway/src/slides-command-gate.js，实验入口保留在 scripts/voice-slides-control/。它已与真实 SlidesCoordinator 做合成组合测试，尚未连接普通 Provider、页面和授权链路。

## 2. 真实实验

| 实验 | 结果与边界 |
| --- | --- |
| 原话回显核对 | 同一原 23 条用例中，12 条有效回看仅 7 条执行；5 条因识别文字和模型引用不一致被拒绝。11 条反例不切页，故结构符合为 18/23。另有一次单案成功。**不选作主接入方案** |
| 会话工具权限的原 23 条回归 | 23/23 结构符合：12 条回看到预期模拟页，11 条反例没有工具调用或页面副作用 |
| 两次相同“上一页”，第一项完成后再说第二次 | 两个独立 call，模拟页 3→2→1，均正确确认，不需要原话匹配 |
| 撤销待执行项后再提出回看 | 旧项取消，更新工具取得 ACK，再接受新请求；只有新请求改变页面 |
| 旧调用延迟至撤销后再交付 | 本地故障注入下旧工具名返回 CAPABILITY_REVOKED，没有应用旧动作；更新后新的回看正常执行。两次分别覆盖早期及收紧输入开始边界后的版本 |
| 改口／撤销 × 未派发／已派发 | 四类均取得符合预期的样本：未派发可替换／取消；已派发保留实际事实，不伪造回滚。派发中撤销有一次首请求未调用工具，另次复测成功，失败仍保留 |
| 普通插话 | 原动作完成，接住新问题，没有多余翻页 |
| 明确追加“再往前翻一页” | 在第一次等待期间输入，两个动作生效，最终到第 1 页 |
| 待处理期间原句重复一次 | 原“interrupt-add”样本只执行一项，模型视作对同一请求的催促，未达到原实验的两动作预期。**未将此失败改成通过**；另增明确含“再”的作者材料单列验证 |

本阶段共 **62 次真实连接：原话方案 27 次、会话权限方案 35 次，均实际 ready**。62 次不是全部通过：包含原话不匹配、重复原话无法区分、一次初始工具未触发、一次待处理重复句未触发追加等结果。分组及源版本见[去敏汇总](2026-10-26-voice-slides-control-stage4.json)。各组不是同一最终版本统一评测，后续模块迁移和容量保护另以合成测试验证。

所有页面执行和初始历史仍是 synthetic。迟到交付由本地注入，不把它冒充供应商实际乱序。工具选择、结果回传、更新 ACK 和回复来自真实豆包。作者回复文字由本助手审阅，独立 Judge、真人听感和浏览器音频验收均为零。

## 3. 这个方案解决和没有解决的事

可确定性检查：旧批次不能重新准入；重复 call 不再次产生副作用；更换工具名但复用旧 call_id 会冲突；旧 ACK、更新期间开始的输入和旧 final 不能开启新权限；跨连接工具名不被接受；容量耗尽停止新操作但保留原事务去重。已接受、已派发动作的事实仍由协调器及组件回执决定。

没有解决供应商原生 FC→输入的直接关联。工具名称代次是应用协议，不是供应商话轮字段。模型仍可能误判语义或在新权限下生成一个新的错误提案；不能把拒绝旧调用推导为永不误判。当前方案仅适用于本会话受限页面操作，不作为学习记录来源、跨业务授权凭据或已具备完整课程推进的证据。

同一有效代次里首次到达的调用仍按宿主接受顺序处理，不能从缺失字段恢复原始发言顺序。例如供应商若把先说的撤销晚于后来回看交付，且尚未发生权限废止，应用不能证明它们原先的语音先后。此边界没有被本轮解决；本轮只支持继续默认关闭的工程接入，不是完整乱序／最新意图语义验收通过。

先前“每个页面 FC 必须唯一归属学习者输入”的设计改为“页面事务唯一归属授权会话、call 及权限批次；语音／学习话轮保持原生归属”。这是明确的架构调整，不是把缺失的来源字段标为已验证。历史报告的未通过结论保留。
