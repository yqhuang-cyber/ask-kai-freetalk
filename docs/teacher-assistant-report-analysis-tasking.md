## 1. 报告要解决什么

每条分析按“具体表现 → 对应证据 → 解释及限制 → 下次练习”组织。报告分别回答：

- 情境理解：回答和什么问题相符？是否请求重复 / 澄清？实际听觉理解能否确认？
- 口语表达：传达了哪些信息，如何组织句子和内容？哪些观察规则未覆盖？
- 沟通支持：是否主动求助？提示是否真正送达、表达是否独立，有无可靠依据？
- 发音与语流：音频评测能力是否可用、适用范围是什么？未接入时明确未评估。
- 教学行动：优先练什么、为什么、怎样练、下次观察什么？没有可靠错误时给探索 / 拓展练习，不制造薄弱点。

描述只限本次尝试；不推断整体听力 / 口语等级、正式 HSK、长期掌握，也不把尝试次数或话量换算成能力分数。

## 3. 独立听力观察任务

**LST-01（已实现的子集）**：仅在所属最新输入轮的回复完整转发、未截断，且下一段有效 final 与受支持的问题类型语义相符时记录。下一段不相符、回答含引语 / 转述 / ASR 不确定、存在未完成回复，均不建立该观察；不跨越中间输入继续匹配。问题只保留必要问句，非整段 Kai 回复。数量短答可以成为情境问答观察，不能因此把完整点单目标判完成。

这只是“此前发出的问题与这次回答语义相符”，不证明学生先听到问题再作答。学生可能提前说完但 final 晚到；播放、字幕、英文、拼音与示范的支持仍未知。报告明确写出限制。

**LST-02**：输入固定计划与最小上下文窗口，输出问题类型、预期理解点、回答相关性、澄清 / 重复 / 英文帮助请求和不确定原因；每项绑定真实问题与学生表达。测试同义改述、简单正确短答、答非所问、自述没听懂、文本混语、含糊指代和 Kai 问题本身不清楚。不得把未给有效机会、沉默、拒绝或识别错误归为理解失败。

**LST-03**：先验证实际适配器提供的输入 / 回复身份与时间范围，不能杜撰供应商字段。浏览器播放声明须绑定会话、回复和取消代次；排队、静音、输出取消、重连与旧回执不能证明已听到。分别记录文本到达、实际播放声明与输入时序；字幕开启时只给混合渠道观察。首版若无法消除歧义，继续描述情境回应，不给纯听力结论。

## 4. 独立口语表达任务

**SPK-01（已实现的子集）**：使用版本化作者规则观察识别文本中的信息和组织形式。明确的“我喜欢……因为……”记录理由连接，不能扩大为理由充分、语法完全正确；“先……然后……”记录先后组织，不能扩大为叙事能力已掌握。一次求助只说明主动使用策略。再次使用需要至少两个不同学生轮次，不称无提示迁移。

**SPK-02**：为昆虫描述、经历叙事、指定句式和点餐变体加入异步语义候选分析。沿用已授权业务边界与 fence，不默认保留整场逐字稿。抽取时保留最小必要上下文，不从孤立句推断错误。

验收要求：

1. 每项结论有维度、具体观察、最小原文引用、轮次 / 事件、能力版本和不确定原因；明确“已观察 / 候选待核对 / 未评估”。
2. 分开评价信息可理解性、词汇选择、语法适切性、内容组织、主动互动和自我修正；不按词数或回答长度替代能力。
3. 错误诊断需可核对的语言事实。尊重合法变体、地区表达和中途自我修正；“经常”需至少两个不同有效轮次，且排除重复事件。
4. 模型不能自创来源、用 Kai 示范作学生表现、把计划作执行、把缺失作失败。保留模型失败与规则降级来源，未通过能力门不提升结论强度。
5. 用独立作者用例与教师盲审覆盖同义表达、引语 / 否定 / 转述、语义变化、题目不清、ASR 不确定、跨轮 / 跨目标混入、长回答 / 截断。预先冻结放行门槛，不能只报告样本内成功案例。

## 5. 发音评测必交付任务（P0）

用户最新明确要求覆盖本次自然对话中的发音分析，任务详见[深入报告 AUD-01～04](conversation-report-deep-analysis-tasking.md)。AUD-01 在早期验证自然说话、声母 / 韵母、声调和语流的可测路径；AUD-02 同文本记录一起建设必要学生音频、说话人 / 轮次归属和对齐；AUD-03 接入真实评测，给可定位的证据、标准示范与优先练习点；AUD-04 完成专业标注、独立声音 holdout 与真人设备 / 教学验收。

仅有转写、ASR 正确率、模型主观赞美、朗读测评或供应商分数均不能代替自然对话发音能力。合法口音 / 变调、误识别、噪声和混合声需单独处理。个案音频不足可显示未评估，但产品整体缺少发音评测不能算深入报告 feature 完成。

此处改变的是新 feature 的交付范围。下面“首版未保存原音”的说明仍是当前已运行版本的事实，不代表新方案仍将音频排除在外。

## 6. 首版实现与证据留存

`EvidenceRecorder` 保留最多 24 条目标表达、24 条组织形式、12 条帮助、24 个回复元数据与 24 组有效问答。遍历从开场到封口的接受轮次，上限 1000；达到任一容量上限显示截断。不能把只保留早期片段说成完整覆盖。Kai 回复仅在内存中有界累积 320 字，用于识别受支持问句；持久证据不含整段回复或原音。

报告由已封口且授权有效的证据生成，绑定计划 / 尝试 / 会话 / evidence hash。首版只准入确定性的作者规则：提交前重算并校验整份分析，防止替换来源或虚构结论。未来模型分析器需要独立校验与准入，不能只通过 hash 就放行。原有异常、删除、权限与异步写入屏障继续生效。

当前沿用本机 SQLite 的显式数据删除与授权限制；尚未实现自动 TTL / 全量异步抽取 / 分布式任务。此缺口属于完整 TA-12 / TA-17，不代表已完成。旧 evidence fence 可生成有限表达分析但不会补造问答关系；已生成的旧报告保持原版本，重新提交新练习才会新增观察，本轮不批量改写历史。
