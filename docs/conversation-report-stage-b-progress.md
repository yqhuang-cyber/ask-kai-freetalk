# 对话报告阶段 B：实施进度

日期：2026-10-27。分支：`codex/report-analysis`。**工程链路已有可测试成果，阶段 B 尚未完成声源、对齐及真人设备验收。** 本文件区分真实运行、合成验证与待办；没有把旧规则报告或音频候选当作发音评价。

## 本轮实现

- **独立报告进程**：M4 数据服务为唯一 SQLite writer；独立进程以专用内部凭据领取任务、续租并提交旧规则报告。结果绑定 attempt、计划和证据 hash；租约过期、撤权、删除或伪造结果无法写回。进程故障可重启，外呼结果未知的任务不自动重试。worker 增加当前委托下的文本 / 音频快照读取，逐次校验提交 hash、租约及当前授权；当前没有外部模型 / 腾讯调用。
- **授权文本账本**：实验开关启用后，学生选择保存文本，M4 增量记录已接受的学生识别文本和安全门后转发的 Kai 文本；控制语句单独标记。有界队列、幂等事件、容量与丢失范围；关闭时有界 flush 并封口，提交固定来源 hash。已持久但未封口的事件在重启后标为 interrupted，不会被认成完整记录。撤回或到期删除对应文本，提交事实仍保留。
- **实验录音链路**：仅显式开启实验开关、学生另行选择时，处理 16kHz 单声道 PCM，候选分段有采样范围和大小限制，经授权异步写入 M4 私有文件。按声音能量筛选只是实验性候选检测，不是经验证的 VAD；环境声和 Kai 回声可能进入候选。说话人、重叠、对齐、噪声均保持 unknown，未检测到削波也不假称音质合格。音频清单固定文件 hash / 来源 / 范围并绑定提交；读取再次核对 lease、权限和 hash。无声音 / 失败不会假称保存成功。
- **独立控制与删除**：文本和音频分别授权、过期 / 撤回；撤回音频后实时停止该录音路径并删除片段，不结束对话、不删除仍授权的文本。文件删除失败保持撤权，返回失败并可重试，重启 / TTL 清理残留；账号删除和教师撤权包含音频。文件不记录到日志，`.pcm` 与本地数据库路径加入 Git 忽略。逻辑删除和权限回执不等于磁盘取证擦除或供应商删除。
- **对齐候选契约**：校验独立来源的音频采样区间、识别文本引用、快照、会话 / 学生 / 权限代次和算法版本。ASR 到达时间不用于推断发音时间；候选始终待核对，不声明参考文字、说话人或发音已验证。**没有接入实际对齐器。**

## 启用边界

- `ASK_KAI_TA_TRANSCRIPT_ENABLED=1` 和 `ASK_KAI_TA_AUDIO_EXPERIMENT=1` 仅供隔离 POC 测试，默认均关闭。音频实验说明明确可能包含背景音和回声，不启用发音诊断。旧说明版本的选择不会自动授权新版本，必须重新告知并选择。
- 独立音频授权不要求开启文本；若无获准音频或数据质量不足，照常允许明确提交，但报告不能把该维度说成已评。音频实验开关不是 Tencent 接入开关。
- 环境 / 设备、说话人归属和语音起止没有可靠验证前，不将实验候选用于真实学生的发音评价。现有豆包 speech candidate 是识别线索，不证明 VAD 起点或学生身份。
