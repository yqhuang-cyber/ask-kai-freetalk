# 作者音频与实际回合、呈现证据

Task05-07工程实现。每个作者音频段单独记录案例、轮次、音频哈希、实际识别回合标识及回复关联。单一匹配与碎片、未确认分别标记；多个供应商回合不合并成一条正式回复。关联依据为采集器当前输入窗口，并不证明供应商只收到了该段、语义一致或用户听到了音频。部分失败与多段关联不得进入完整轮评分，旧历史记录仍按旧完整性标记复核。

Web受限诊断按实际回复归属汇总浏览器音频观察、队列、播放时钟、字幕渐进及迟到事件丢弃。没有浏览器观察的播放量保持未知；服务器完成、已转发或评测收到音频不构成播放证据。诊断继续只保留别名、计数及枚举，观察失败不阻塞对话，原打断和输出隔离机制不变。

040／036／011继续作为真实诊断范围，历史超时和跨轮残段根因仍未完全定位；本项不改供应商分段、VAD、静默时限或输入语速。合成多终轮、乱序及取消回归与真实Web体验分别登记。
