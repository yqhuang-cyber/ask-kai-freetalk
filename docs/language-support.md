# 中文优先与自适应英文支架

需求扩展见[自适应语言支架需求](adaptive-language-scaffolding-requirements.md)。该需求尚未实现；本文件记录当前策略与实现边界。

2026-10-10。按用户确认的 PRD §5.4 解释，调整 Task 04 的固定中英句对。
三个入口共用 `kai-hsk1-v3`、`kai-reply-v2`、`kai-language-v1`。
工程和合成测试已覆盖；本轮没有调用真实豆包生成或真实 Judge，模型实际遵守及听感仍需验收。

| 学生状态或请求 | 支架策略 |
| --- | --- |
| 未知画像／初学者，未声明已知表达 | `required`：短中文后给对应短英文 |
| 已知表达，或明确自述能听懂中文 | `adaptive`：已知、容易理解的交流可省略英文；新表达仍给必要英文 |
| 新表达求助或没听懂 | 恢复 `required`；英文只解释当前中文，不增加知识点 |
| 明确要求只用中文（`zh`） | `off`：先简化中文帮助；学生请求英文或恢复自动模式时再切换 |
| 明确需要常规双语（`zh_en`） | `required`：保持简短对应英文 |
| 自动模式（`auto`） | 结合理解自述、已知表达与当前求助；未知情况仍有英文支持 |

始终中文先说；英文若出现，紧接它对应的中文。默认一句短中文，最多两句及必要英文。
两种语言继续共用 36 汉字、24 英文词、48 合计单位、180 总字符的预算；最多一个主要问题／任务、一个新点和一个短示范。
省略英文不增加中文、知识点或任务预算。口头告别保持简短，现有 Web 结构化总结及其双语卡片继续使用。

## 最小画像与来源

画像继续经过签名授权、owner/learner 范围和现有 memory port；POC 使用仓库内的本地 mock HTTP 服务。
没有新增外部 HSKai 依赖、数据库、SDK 或逐轮第二个规划模型。
原有兴趣、纠错偏好继续保留，总计最多五个唯一字段。

| 字段 | 值与限制 | 含义 |
| --- | --- | --- |
| `support_language` | `auto` / `zh` / `zh_en` | 英文支架偏好，不能改变中文先说及安全规则 |
| `chinese_comprehension` | `beginner` / `comfortable` | 授权画像或学生自述，不能当作客观水平评分 |
| `known_expressions` | 最多 12 个不同中文词／表达，每项最多 16 字符 | 有来源的已知内容，用于支架选择；不是本轮学习成果 |

记录保留 `source`、`updated_at`、`expires_at`；只接受 `authorized_hskai_profile` 或 `student_correction`。
过期或不合法数据不能降低默认英文支持。Web「我的偏好与记忆」支持查看、更正、导出、删除；
已知表达可输入 `茶，音乐`，理解情况可输入 `beginner` 或 `comfortable`。
保存更正仍经授权接口，来源为学生更正，30 天过期，作用于后续上下文边界。
删除继续撤销当前授权会话，mock 重启仍清空这些数据。

完整、有效且去重的 `user.final` 可以更新当前会话的直接请求，例如「只用中文」「用英文解释一下」「恢复自动模式」「我听得懂中文」「我没听懂」。
明确自述「我已经会“茶”了」可加入本轮已知内容，并保留来源话轮／事件。
这些口头变化仅在当前会话生效，不自动写回长期画像；后续通过 Web 保存的相关更正优先于旧会话偏好。
普通中文发言、说出目标词、成功 ASR、课程完成、教师话术、部分识别、重复／外来事件均不会自动升级理解或掌握。
引语、否定和讨论语言规则不会成为控制请求。

规则识别器只处理一组明确、保守的请求，不能替代语义理解。
基础模型指令仍要求结合最新学生意图判断实际回复中是否出现新表达；`adaptive` 不是无条件免除英文。
教学动作建议也不能证明某个新点已经讲过或学生听懂。

## 运行时与诊断

会话创建和上下文更新同时携带语言策略及当前状态。更新继续在回复边界发送，等待准确版本 ACK，
不改变持续采音、打断、回复所有权或迟到事件隔离。
实时模型已收到最新学生输入，但第一条回复可能早于服务端的新上下文 ACK；不宣称更新能重写已生成音频。

每条回复的审计在其开始通知处固定已 ACK 的支架状态。
后续画像修改或 ACK 不会重判旧回复；未 ACK 的变化、相关状态不匹配、取消／失败／空白／截断输出不产生确定的语言违规结论。
相同支架输入即使话轮来源变化，也只说明规则输入一致，不能证明模型使用了哪个上下文或学生听到了什么。

诊断新增 `language.decision`、语言版本、支架模式、原因和已知表达数量，以及
`language_context_matched`、`english_support_issue`、`language_support_review_required`。
导出只包含计数、固定枚举及匿名话轮引用，不包含已知词、偏好正文、学生／教师原话或音频。
审计不裁剪、重排、补译或因长度取消正常输出，字幕仍按原文和播放进度渐进显示。

## 原有十维评测

`kai-content-v3` 保留原有十维、权重和安全门槛。无画像时仍按初学者双语检查。
可选案例输入 `initial_memory` 使用相同字段及来源验证，并必须提供 `profile_at`，
按该固定时点校验记录，避免历史用例因运行日期变化而改变支架。
每轮预期状态只由初始数据和此前的学生发言派生；不使用待测 Kai 回复、参考答案或未来回合推断画像。
调用 Judge 时重新生成 `language_contexts`，调用方传入的同名字段不能替换预期。

纯中文或部分句子省略英文在 `adaptive` / `off` 下可以满足表面顺序；英文优先、分组翻译或额外英文仍会被检查。
初学者缺少英文，以及中文偏好下仍提供英文，保留独立失败检查。
字符和句子计数无法判断“已知内容是否覆盖当前句子、新表达是否需要帮助、翻译是否准确”，
这些由原有 Judge／人工在 instructions、level、expression、personalization 和 P0 `adaptive_scaffold` 中审核。
合理省略英文不扣分；不确定仍需审核，明确失败仍阻断，高平均分不能掩盖失败。
