# 拼音字幕首版实施与试用

日期：2026-10-26。普通 Provider／Gateway／Web 已接入，默认显示字幕拼音。本轮实际试用页为本机 `http://127.0.0.1:4311/`；原 4310 服务保留。需求见[PRD](prd/pinyin-captions-prd-v1.md)，历史隔离实验见[Spike](pinyin-captions-spike.md)。

## 实现

- `CaptionAnnotations` 在原 Presentation render 边界创建安全的 ruby／rt 文本节点，对完整可见上下文转换后再保留 previous／current 高亮。原正文、音频、计数和播放时间不变；英文和符号原样保留，异步加载完成只重绘最新帧。
- `pinyin-pro@3.29.5` 和 `@pinyin-pro/data@1.3.1` 固定版本加入 dependencies／lockfile。静态白名单只提供基础 UMD 和小型繁体映射，不把完整大词库传给浏览器，不用 CDN 或外部转换服务。沿用 spike 发现后的两条词语覆盖；未新增开放文本质量通过率。上游声明许可分别为 MIT／ISC。
- 页面默认勾选“显示拼音”，保留总字幕开关和字号；开聊前示例明确标注，未连接时不冒充真实回复。预览比较不会保存偏好，新对话按默认显示。
- `classifyCaptionPinyin` 只识别完整明确命令，否定、引用、讨论、混合任务及对立指令不触发。已接受 `user.final` 是入口，使用原生实际输入话轮，不增加新意图模型、不扩展原生工具家族。
- `CaptionSettings` 维护授权 WebSocket 内的目标设置和 revision。Web ACK 精确匹配请求后才更新确认状态，固定确认语仅一次；回执超时或依赖失败只报告未确认，不阻断普通语音。手动设置共用此链路、不生成虚构学习者话轮。
- `TeachingSession` 完整上下文纳入已确认显示设置；它不是持久画像、学习证据或实际发音。语速、教学、课件仍共用既有完整配置更新与串行确认。
- 确认语复用已验证的固定语音与 SpeechPlayback 通道，保留实际 request／turn／response ID。普通插话保留页面请求，但取消旧语音确认；连续开关只确认新请求。

## 验证结果

| 层级 | 结果与范围 |
| --- | --- |
| 合同／合成 | `npm run verify` 636／636；三个 replay 正常／插话按预期关闭，故障场景按预期失败，证据仍 attempted-only |
| 真实豆包 | 普通 Gateway 连续三轮“关闭→打开→关闭”最终通过，每轮一次固定确认且在 synthetic 页面 ACK 之后，收到音频；另有修复前同方向三轮通过。使用作者 PCM；页面和播放回执模拟，无浏览器和人工听感 |
| 普通浏览器 | 最终代码 CUA IAB：8 个拼音场景全部通过，12 个原有课件／调速／重连／故障场景全部通过。真实 HTML／web.js／渲染／AudioIO 输出与回执，语音 peer 和 Planner 显式 synthetic，无麦克风 |
| 实际试用页 | 普通 POC 4311 默认注音、预览开关与字号人工浏览器操作已核对，尚未从该页上传真人麦克风或做听感验收 |

拼音 8 项分别为中英混合默认注音、手动隐藏、后续回复继承、手动恢复、语音关闭及已渲染确认、语音开启及注音确认、隐藏全部字幕、新会话恢复默认。真实供应商 CLI 不能代替实际浏览器回执，浏览器合成不能证明真实模型理解；两类证据分开。

### 保留的问题与修正记录

首次完整回归因历史基线测试读取当前新增依赖而失败；改为隔离原依赖／锁文件 fixture，并增加依赖及锁漂移拒绝断言，**没有修改归档 baseline 或放宽运行守卫**。最终 636 项通过。

普通页面连续自动化曾两次在“结果未知→结束”等待连接释放超时，直接点击结束及独立复查成功；增加 CUA 每次点击前后最新 UI 观察后，最终 12 项完整通过。未将前两次超时删作全通过。

拼音页面首次连续开关发现：final-only ASR 建立新设置后，对上一条固定回复的插话又取消了新确认。修复为只取消旧话轮控制，保留最新输入所归属请求；新增普通 Gateway 回归，最终 8 项拼音与 12 项既有场景均重跑通过。此前失败记录保留在本地忽略目录，报告只留去敏描述。

## 试用和剩余边界

页面开聊前就能看到“你好，今天想聊什么？”的拼音示例，可勾选／取消“显示拼音”比较。开聊后试说“关闭拼音”“重新打开拼音”，设置只影响本场；语音播放中文不加逐字拼音。

当前只执行明确单独命令；混合任务与更宽泛自然表达尚未接入 FC。开放文本多音字、人名、字音与实际语音一致性、手机宽度与低端设备性能、真实浏览器＋真实供应商联合麦克风／听感、极端连续插话仍需后续验证。

机器可读分层汇总及最终源码哈希见[实施结果 JSON](eval-results/2026-10-26-pinyin-captions-implementation.json)。实验工具都在 `scripts/pinyin-captions/`；原始音频、供应商 trace、作者回应和截图保存在忽略目录，不提交真实学习者内容。
