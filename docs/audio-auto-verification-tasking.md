# 作业录音：自动核验优先的流程与任务

日期：2026-10-28。状态：**本地工程链路已实施并通过合成验证；腾讯 ASR 真实联调、真人录音与教学校准待验**。用户明确：老师无法逐段回听所有作业，期望 AI 承担核验，接受后台分析耗时增加。对应 AUD-02 / AUD-03 / AUD-04、M4-02、DR-08；发音仍是 P0，不以取消人工节点代替真正评测。

## 1. 当前问题与产品决定

现有 `AudioCandidateSegmenter` 只做能量候选切片，最多约 5 秒截段；speaker、噪声、重叠、缺帧等大多 unknown。`audioEligibility` 要求来源和质量通过，而 `AudioReviews` 仅接受教师声明，导致没有人工核对就没有合格音频；`submissionView` 又让学生等老师操作。因此这不是只改一个按钮的问题，缺的是自动音频准入能力。

将必经的“老师核对录音”改成 **“后台音频预处理与自动核验”**。正常作业不要求老师逐片段操作。教师保留可选的疑点查看、纠正和抽查；老师不处理疑点时，系统仍须完成可完成的深入报告，不无限等待。

不通过修改 `ASK_KAI_TA_AUDIO_ASSESSMENT_VALIDATED`、批量勾选、将 unknown 全部写成通过，或让文本模型假装听音频来完成这项需求。当前 MiniMax 适配只读取文本；需补直接处理音频的识别 / 声学检测链路。

## 2. 目标流程

学生明确提交 → M4 创建持久分析任务：

- 文本分支：按当前流程做目标、理解与表达分析。
- 音频分支：检查采集来源 / 完整性 → 人声与句子分段 → 回声 / 噪声 / 多人重叠检查 → 音频识别及时间对齐 → 挑选可评测语音 → 腾讯发音评测。

两分支并行；音频分支内部按实际依赖执行。分析全部完成、达到明确覆盖限制或耗尽重试预算后，汇总并发布深入报告，不先用基础记录顶替。正常路径不再有“等待教师核对”审批门。

后台可以比现在耗时更长；页面展示“音频核验中 / 发音评测中 / 正在汇总报告”。学生和老师均可离开页面后回来查询，不要求保持连接，不先承诺固定分钟数。先基准测量，再确定正常耗时目标与总截止时间。

## 3. 自动核验实际需要判断什么

### 采集来源与回声

分别记录学生麦克风通道、Kai 输出参考及实际播放时间线，绑定真实采集样本区间与会话；不把二者混成一条供评测的音轨。不以 ASR final 到达时间推断说话时间。

综合麦克风来源、Kai 播放参考、回声相似性、语音活动及多说话人线索，判断某段是否适合当作本次学习者语音评测。说话人分离只提供不同说话人线索，不证明真实身份；默认不新增声纹注册。旁人、回声或重叠无法分清时不计学生成果。

### 质量、自然边界与对齐

保留原始 PCM / hash。静音、过低音量、削波、实际缺帧、噪声和重叠分开检查，附方法、版本、置信度及适用范围；不把“没有检测到”写成绝对无缺陷。能力未经验证时不能自动放行。

有前后缓冲的语音活动分段与带时间戳识别用于形成可追溯句段；现有 5 秒片段只是存储 / 传输块，不能直接视为完整话轮。仅在样本区间连续、来源一致、缺口明确时重组，不能拼接跨说话人或缺失内容来制造完整句子。

音频识别保留原始口语、重复、自我更正及不确定项，不启用口语润色成书面语来覆盖学生表现。原音、实时转写、离线转写、对齐候选分别保存。去噪视图可辅助识别，发音评测不得静默替换成经美化的声音。

## 4. 服务职责与评测路径

**优先技术验证候选：腾讯录音文件 ASR 做词级时间戳及必要说话人线索，现有腾讯智聆新版继续负责发音评测。** 腾讯 ASR 的具体引擎 / 版本、权限、费用和本机接入均需验证，不能因 SOE 密钥已配置就标成 ASR 已开通。噪声 / 回声 / 重叠准入另以真实音频校准，不把 ASR 宣传能力直接当成质量认证。

官方[录音文件识别请求](https://cloud.tencent.com/document/product/1093/37823)提供带词时间戳的返回形式及部分引擎的说话人分离，适合作为异步对齐候选；调用参数与真实结果仍需逐项检查。选择保留口语的输出形式，避免改写口误的输出用于教学证据。

发音分两条路径：

1. 自动核验合格的自然对话先走**自由说**，不要求老师先抄写参考文本。官方[中文自由说](https://cloud.tencent.com/document/product/1774/107398)允许无参考文本，列出的维度为单词精准度和流利度；不能因此承诺逐字声调 / 音素诊断。
2. 声调 / 音素等精细分析走单独验证过的短句对齐路径。机器推断的参考文本有独立依据和不确定性，不能套用 `teacher_reviewed` / `author_verified`，也不能直接把 ASR 文本当成绝对正确参考。缺少可靠参考的词不硬判发音错误；必要时给学生一条可选的短补录任务，不能让每份作业都重新跟读。

MiniMax 使用已产生的核验 / 评测证据整理报告和建议，不凭文字推断声调或声母韵母。自由说及精细路径都需真实原音与教研核对后准入；发音 must-have 不因先实现自由说就整体关闭。

## 5. 处理结果和教师负担

| 结果 | 后台行为 | 师生看到什么 |
| --- | --- | --- |
| 可评测 | 自动评测并汇总，记录实际覆盖 | 正常深入报告，老师无需点击 |
| 部分片段不可靠 | 排除这些片段，继续评测其余可用部分 | 报告说明覆盖和原因；可选查看少量疑点 |
| 全部不足或持续失败 | 自动重试到预算终点，保留未评估维度，必要时建议学生补录 | 发布明确受限的深入报告，不无限等老师，不把录音问题判成学生能力差 |

教师默认看到完成摘要和需要教学关注的结果，不展示全部切片的操作列表。疑点按原因聚合、定位到必要原音，保留可选纠正；老师的纠正是新的版本化证据，并使相关音频结果重新计算，不改写原始封口内容。

## 6. M4 与授权边界

- 新增独立版本化的自动核验结果，绑定原始音频 hash、样本区间、manifest、授权代次、模型 / 算法版本、发现和置信度、准入结论与未处理覆盖。保留人工 review 为独立证据，不把 AI 结果伪装成人工签字。
- 新的音频识别用途 / 服务需更新告知和配置；旧音频不静默升级用途。读取、外呼、重试、回调 / 轮询、结果写回和报告查看都复核当前权限、来源和 TTL。
- 自动识别是有依赖的持久子任务，长耗时异步请求不能硬塞进现有单轮 120 秒 worker 范围。保存外部任务引用、下一查询时间、重试和截止时间；释放等待中的执行资源，崩溃后恢复，不重复上传不确定是否已受理的音频。
- 权限撤回 / 删除 / 到期清除识别文本、对齐、核验结果、原音、外部任务引用及派生报告，拒绝迟到结果；不复活旧来源。
- 取消人工主门必须以自动核验达到准入为前提；开发期间的人工测试路径保留明确标识，不提前把运行界面写成已自动完成。
